# 服务方法体系与人格设计

## Skill 体系结构

项目以阅读营老师的日常服务工作为基础，将不同业务场景整理为相对独立的服务方法，在系统中称为 Skill。每项 Skill 对应一类明确的服务目标，说明适用场景、所需事实、处理步骤、表达要求和完成条件，供智能体在处理家庭消息或主动服务事项时按需使用。

截至本次候选版本，共保留 **49 个活动 Skill**。这些 Skill 按主要职责分为八组，共同覆盖服务入口、阅读督学、家庭答疑、成长反馈及内部规划等工作。

| 服务类别 | 数量 | 主要职责与适用场景 |
| --- | ---: | --- |
| 主入口与通用表达 | 2 | 识别当前服务需求，组织业务分流，并统一回复对象、语气、篇幅和表达要求 |
| 阅读督学与学习节奏 | 11 | 围绕课前邀请、完课鼓励、历史补读、阅读衔接、周度总结和回归欢迎等场景开展服务 |
| 家庭答疑 | 8 | 处理阅读内容、常见问题、学习效果疑虑、投诉反馈、资料核实、孩子分享及答疑归档 |
| 家庭信息与安排 | 4 | 处理督学咨询、已有服务安排、家庭称呼记忆和正式服务分层信息的读取 |
| 互动与节点关怀 | 4 | 围绕阅读互动、节日考试、生日及节日祝福提供相应服务 |
| 高光与成长反馈 | 12 | 根据课程开始、阅读里程碑、精彩表达和阶段成长等事实，组织相应反馈与材料 |
| 内部规划与复查 | 6 | 支持当日规划、完课后规划、主动服务判断、家庭资料及持续事项复查 |
| 媒体辅助 | 2 | 支持理解家庭授权图片及生成阅读音频素材 |
| **合计** | **49** | 各类服务方法按照具体场景共同发挥作用 |

Skill 的组织包括主入口、场景分流、具体服务方法和参考材料几个层次。主入口结合当前消息或任务判断服务目标；需要进一步分类时，进入答疑或督学等业务入口；确定场景后读取相应服务方法，并在必要时参考案例或规划要求。回复表达规范贯穿各类场景，使不同服务保持一致的角色定位和沟通分寸。

一项具体服务可以结合多个方面的要求。例如，孩子提交阅读题答案时，需要由阅读答疑方法确定如何核对题目，由课程知识提供答案依据，再依据通用表达规范组织回复。家庭要求调整已有提醒时，需要结合安排管理方法、当前事项状态和家庭原话处理。

不同业务动作可以共用同一份 Skill。例如，周互动的不同角度共用一份服务方法，生日相关服务也可以共用同一方法和交付记录。因此，49 是候选版本中活动 Skill 的数量，业务动作编号和具体服务次数另行统计。各项服务的接口接入与验证进度不同，需查阅对应版本和场景的验证记录。

## 主要服务类别及业务作用

### 阅读督学与学习节奏

阅读督学围绕孩子在一个学习周期中的进展开展，覆盖课前、课后、学习中断和阶段回顾等环节。各项服务以课表、实际完成情况、历史缺课和家庭沟通记录为依据，形成与当前学习状态相适应的提醒或反馈。

| 服务环节 | 代表性服务 | 主要判断依据 |
| --- | --- | --- |
| 课前引导 | 当日阅读邀请 | 当天课程安排、可用导读材料及家庭联系限制 |
| 课后反馈 | 完课表扬、连续阅读鼓励 | 真实完课事件、连续阅读记录及已交付内容 |
| 学习衔接 | 历史补读、防止跳课、恢复阅读节奏 | 当前与历史课次状态、实际缺课及家庭近期情况 |
| 周度服务 | 周末补读邀请、周度总结 | 本周应学课次、已完成及未完成课次、对应周总结材料 |
| 重新开始 | 回归欢迎 | 此次完课与此前学习记录之间的关系 |

这些服务在确定执行前，需要结合最新事实复核。孩子已完成原先计划提醒的课次，或家庭已提出暂停要求时，相关事项应根据实际情况调整。一次真实完课可能同时涉及多个服务判断，系统还需要结合已有记录进行合并和去重。

### 家庭答疑

家庭答疑包括阅读内容、常见业务问题、学习效果疑虑、投诉反馈、未知问题核实和孩子主动分享等场景。答疑入口负责结合问题性质选择相应服务方法，普通问候和致谢根据上下文直接处理。

阅读答疑重点核对书目、课次、题目和来源答案；课程、产品及操作问题依据相关业务资料处理；家长表达学习疑虑或提出投诉时，服务应回应对方指出的具体问题。对于问题已经明确但必要资料无法取得的情况，已设计提交人工老师核实的处理方式，并记录待核实内容。

### 家庭信息与服务安排

该组方法处理家庭来信与既有服务之间的关系，包括请假及补读咨询、查看或调整已有安排、依据家庭原话记录称呼，以及读取正式服务分层信息。

例如，家长要求提前完成一项已经安排的服务时，需要先核对实际存在的事项，再将本次交付与该事项关联。家长更正称呼或说明临时安排时，需要保存其主体、原话及适用时间。涉及正式服务分层时，应使用已有且适用于该家庭的有效信息。

### 互动、关怀与成长反馈

互动与节点关怀围绕阅读交流、节日、考试和生日等适用场景开展，关注家庭当前情况和联系节奏。高光与成长反馈围绕课程开始、阅读里程碑、精彩表达、阶段成长和相关材料，帮助家庭了解已经发生的学习进展。

成长反馈需要与事实依据相对应。例如，系统记录孩子完成了一本书时，可以围绕这一完成事实给予反馈；如需描述阅读能力变化或生成成长材料，还需要相应的内容依据及可用的业务能力。

### 内部规划与媒体辅助

内部规划与复查服务支持每日服务安排、完课后判断、家庭资料复查及持续事项检查。其处理结果为具体服务提供依据，相关外发仍需结合当次事项条件和交付结果。

媒体辅助包括对家庭授权图片的理解和阅读音频素材生成。图片或音频生成后的实际使用，还需要结合当前渠道支持情况、素材授权和发送结果判断。成长视频和微信语音投递等能力仍有待进一步接入和验收。

## 单项 Skill 的设计

每项 Skill 围绕一个相对明确的业务目标进行编写。根据服务性质，内容通常包括以下方面。

| 设计内容 | 主要说明 |
| --- | --- |
| 服务目标与适用场景 | 明确该项服务解决的问题、服务对象及适用情形 |
| 触发条件 | 说明由家庭来信、学习事件或定时检查等哪类情形进入 |
| 所需事实与资料 | 明确需要的家庭信息、学习记录、课程资料、历史事项及素材 |
| 处理步骤与分支 | 说明事实核对顺序，以及不同情况对应的服务方式 |
| 沟通与表达要求 | 规定沟通对象、内容重点、语气、篇幅及需要注意的分寸 |
| 交付与完成条件 | 明确需要完成的消息或材料交付，以及何时可以登记服务结果 |
| 参考材料 | 提供适用案例、规划要求或补充说明，供具体场景参考 |

Skill 主体承担服务处理说明，参考材料用于补充具体例子或规划要求。案例中的称呼、课次和家庭情况只用于说明表达方式，具体执行时需要依据当前家庭的真实信息。

## 典型服务方法

### 阅读内容答疑

阅读答疑的目标是解决家庭当前提出的阅读问题。处理时需要先识别提问对象和问题性质，判断孩子是在核对答案、请求解释，还是家长希望获得可以转述的说明。

在明确书名、课次和题目后，系统查阅对应的引读问题与来源答案。孩子仅询问选项是否正确时，核对后给予直接反馈；孩子追问原因时，再根据需要查阅同课正文，解释与问题有关的内容。书名简称对应多本书，或课次信息不足以确定资料时，先向家庭澄清。

系统在表达时应区分对题目作答的反馈与对孩子整体能力的评价。资料不足以说明其阅读过程或能力水平时，回复围绕当前题目展开。阅读答案专项已完成选定场景的模拟验证，课程资料的业务审核仍需继续完成。

### 周度学习总结

周度总结根据本周课程安排和实际完成记录，形成与家庭学习情况相符的反馈，并匹配对应课程周的总结材料。

服务方法以本周实际应学课数为基础，区分全部完成、部分完成和零完成三种情况。全部完成时，围绕已完成课次给予肯定；部分完成时，分别说明已经完成和可以继续的课次；有应学课程但尚未完成时，关注可能存在的困难，并按实际服务能力提出后续沟通建议。课表或学习记录缺失时，需要保留信息不足的状态。

周总结文件应与实际课程周对应，文件及文字口信分别核对交付结果。文件得到确认后，口信才可说明总结已发出。相关分支已有模拟记录，具体材料覆盖与渠道能力仍需按实际环境核验。

### 已有服务安排管理

家庭对既有服务提出提前履行、修改或暂停要求时，该方法先定位实际事项，核对当前安排、家庭意愿和适用时间，再按相应流程处理。

例如，家长要求现在查看原定晚些时候发送的服务内容，系统应核对该事项是否存在以及当前能否履行。完成交付后，需要将本次结果与原事项关联，供后续到期检查使用。若家庭提出暂停某类联系，应明确其范围和有效时间，并在相应事项执行前重新核对。

## 人格与表达规范

### 服务角色

“多多老师”定位为面向阅读营家庭的阅读辅导老师。人格设计强调耐心、亲切、尊重家庭选择，并能够根据孩子与家长的不同需求提供适当支持。

面对孩子的阅读问题，老师需要关注其当前正在理解或表达的内容；面对家长的咨询，应提供清晰、具体、便于理解的说明。家庭反馈困难或不满时，应认真回应已提出的问题，并依据实际可用的信息和处理能力说明下一步。

### 表达要求

| 表达方向 | 具体要求 |
| --- | --- |
| 贴合当前话题 | 根据近期对话理解指代和省略，围绕家庭当前提出的问题回应 |
| 区分沟通对象 | 根据实际说话者选择称谓与表达方式，家长代问时提供适合转述的说明 |
| 控制交流负担 | 简单问题简洁回答，复杂问题说明必要条件；问题解决后可自然结束 |
| 鼓励具有依据 | 表扬对应真实课次、完成情况或已经出现的表达，审慎描述能力变化 |
| 保持事实准确 | 对尚未核实的信息、未完成的事项和实际交付结果作出相应区分 |
| 尊重家庭意愿 | 对暂停、请假、调整安排及纠正等要求，结合实际记录和有效范围处理 |

在候选规范中，单次回复的文字、图片与表情合计最多 3 个气泡，每条文字最多 50 个字符。具体内容按完整语义组织，普通交流可以使用更简短的回复。表情和图片根据场景及素材条件选择。

### 人格与业务方法的配合

人格规范贯穿阅读答疑、督学提醒和成长反馈等服务，指导服务态度与表达方式；各项 Skill 规定当前业务需要核对的事实和处理步骤；知识库提供课程及业务资料；执行和交付记录用于确认服务结果。

例如，孩子核对一道阅读题时，阅读答疑方法要求确认题目并查阅对应答案，人格与表达规范要求使用符合孩子理解习惯的简短语言，实际发送后还需以交付记录确认回复结果。涉及长期陪伴和主动联系时，同样需要结合家庭的最新意愿、已有安排和实际学习记录。
