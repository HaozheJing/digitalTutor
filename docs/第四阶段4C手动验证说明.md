当前入口位于隔离K版。程序361项通过，手动CLI已经真实Flash运行过；完整4B/4C关口经独立复验未通过，当前仅供隔离人工评审。本说明不表示已开放主动发送或进入4D。

在服务器使用新目录及新run名称：

```bash
cd /root/autodl-tmp/digitalTutor/work/stage4/4c-development-k
PYTHONPATH=backend/src runtime/backend/bin/python backend/scripts/demo_daily.py \
  --run my-daily-01 \
  --sources backend/scripts/manual_daily_sources.example.json \
  --clock '2026-10-04T10:00:00+08:00'
```

首次只准备虚构家庭、原始学情与已确认的合成规则，不调用模型。交互输入：

- `/tick`：有限执行调度与Worker，由真实Flash自行决定候选、正式事项和今日计划。
- 普通中文来信：作为虚构家长输入，有限运行service后展示实际模拟渠道回复。
- `/clock 2026-10-05T08:00:00+08:00`：只调整本实例业务钟；再用`/tick`检验次日规划。
- `/quit`：结束本轮进程，不启动后台服务。

也可非交互运行：

```bash
PYTHONPATH=backend/src runtime/backend/bin/python backend/scripts/demo_daily.py \
  --run my-daily-01 --resume --tick --once
```

源码、提示词、批准材料或原始来源改变后必须新建run。`--resume`仅恢复同版本的手测实例，不接管验收数据库。来源示例只写原始学情、确认绑定和合成职责，不预造Event、Plan、Report，也不指定模型答案。

输出区分今日成员、未入选旧责任、待规划、未消费报告、未答及来源缺口。生成计划不等于服务完成。`mode=daily`会阻止主动外发；普通有效来信可在北京时间08:00至21:00窗口内回复，实际仍为mock。报告未消费会挡住daily，不能为演示删除报告。

返回码0表示本轮无技术失败或待处理阻塞；1表示执行或导出失败；2表示仍有等待、未答、未消费报告或已达有限步骤。源码固定Flash，不能通过此入口切到max。

每轮证据在 `evaluations/backend-manual-daily/<run>/turn-*`，业务状态在独立的 `state/backend-manual-daily/<run>`。只输入虚构家庭信息，不使用真实uid、作品或聊天。原主目录H的手测实例和历史证据保留。
