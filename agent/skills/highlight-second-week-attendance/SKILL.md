# 第二周全勤鼓励

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取班期第1周、第2周课表与完成记录，明确周边界、全勤口径、补课与请假的处理方式和同步时间。

## 判断与准备

核实第2周全部应上课节符合全勤口径；口径未定或数据未齐时不擅自把请假、补课或打卡计入全勤。第二周达成时评估1次，按学生、班期与第2周成就去重。

对照第1周到第2周的真实参与变化，围绕坚持事实、从尝试到持续阅读的过程组织图文卡。只有两周都全勤才写“全勤二连”；第1周缺课或未知而第2周全勤时仍可以肯定第二周全勤，不能虚构二连。没有可比基线时只描述第二周，不据全勤断言已经形成稳定习惯或掌握课程内容。

## 交付与后续

通过家长私信交付第二周全勤图文卡。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
