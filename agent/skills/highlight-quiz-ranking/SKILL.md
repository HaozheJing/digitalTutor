# 周度课中题正确率冠军

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取周榜规则、题目及作答统计、参与范围、周边界、并列处理、最新榜单快照时间与允许展示范围。

## 判断与准备

按有效规则核对周正确率的分子、分母与适用题目，再确认本周第一名身份。只有权威榜单或授权可核验的计算支持冠军时使用；第二名、个人满分或不完整的内部排序均不能替代。并列、榜单尚未结算或更正未完成时按实际规则处理，不能自行授予唯一冠军。

每周1次且仅冠军，按学生、榜单规则与周范围去重。保存采用的榜单快照和核验时间，发送前查更正；已失效的冠军草稿撤销或重新判断。

## 形成与交付

通过家长私信图文卡表达“本周正确率冠军”，呈现实际冠军事实和对应题目的理解表现。竞争锚点只用于这一真实获胜场景，不贬低其他孩子，也不暴露其他孩子身份；正确率不能单独证明稳定理解能力。榜单对该家庭的可见范围未确认时先核实，不以内部查询权限替代外发权限。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
