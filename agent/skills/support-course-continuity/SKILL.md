# 课程衔接支持

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)及[服务规则](../../config/service.yaml)。核对班期课表、原课节顺序、完课事实和同步时间，并读取家庭消息、暂停、请假、补课约定与近期触达。

例如前后课节已完成而中间一课未完成，可以形成跳课模式候选。先排除合理调整和同步延迟；同一模式发现时一次，已有提醒、约定或暂停时接续原事项，不重新触达。跨动作的原课节补读次数共同计算。多个缺课需要持续安排时关联[补课规划与跟进](../plan-makeup-learning/SKILL.md)。

读取缺失原课节及与其衔接课程的正文，结合真实顺序选择话术。给家长的私聊说明已完成部分、尚待接上的具体课节、真实入口与可选安排；嵌入给孩子的“故事不要断更，一起把这一段接上”鼓励口信。若没有真实时间约定，不把“明天一起续上”写成已经约好。不得把课节顺序直接翻译为“昨天和今天”，除非自然日期也经核实。

发送前重新检查学习状态、新消息、暂停、约定和有效频控。保存模式涉及课节、原版本、依据、草稿、入口、操作号与回执；别名入口沿用同一事项和去重记录。分别记录接受建议、形成约定和实际补完；缺失课节经核实完成才结束对应衔接责任。未知回执先核实原操作，不重复发送。
