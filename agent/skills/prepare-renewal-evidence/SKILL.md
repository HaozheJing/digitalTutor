# 准备成长与续费材料

让老师和家庭看见孩子一段时间内真实发生的学习变化，为后续课程规划提供事实材料。数字老师负责整理和解释，不替家长作购买决定，不把材料包装成保证效果或必须续费的理由。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)、[沟通原则](../../guides/communication.md)，以及[服务规则](../../config/service.yaml)中的 `contact`。确认决策期的起止范围、对象（老师、家长或会议）、输出渠道、级别、书目和课程版本。

“进入决策期”只提供准备材料的入口；同一决策期通常准备或交付 1—2 次，具体次数以当前服务配置和老师安排为准。先读取当前服务状态、家长关注点、已有反馈和是否存在投诉、退费、暂停或未解决问题；风险事项需要转相应人工路径，不用成长材料掩盖。

## 汇集成长证据

按时间顺序取得全程高光卡、真实勋章记录、月度反馈、互动金句、作品、作答和可比较的学习数据。每项材料保存发生时间、课节或书目、原始表达/数据、来源类型和可公开范围；孩子原话与老师解读分开。

区分证据用途：

- 完课、打卡、互动次数可说明参与过程；不能单凭这些宣称理解力、表达力或习惯已经形成。
- 作品、回答、测评和可比较时期可以支撑具体能力解读；比较时核对任务难度、支持条件和课程版本。
- 高光、勋章和月报只在实际存在且适用时引用；缺少某类材料就说明缺口，不生成虚构金句、对比或排名。

可将材料编排成学期成长报告合集：阶段概况、代表性高光、孩子原话/作品、前后变化、当前仍需支持的部分和下一步可选方案。每一项结论都能回到实际记录，未确认的满意度、能力稳定性或续费意愿保留未知。

## 形成可选择的沟通材料

面向老师时输出事实包、证据位置、家长关注点、可讲解的学习收获及仍需人工确认的地方。面向家长时用正向、具体、易理解的语言说明孩子经历过什么、哪些变化有证据、接下来可以怎样选择；不制造稀缺感，不暗示不续费就会失去既有权益。

如果家庭询问下一阶段课程，先依据产品和课程资料回答适用范围、安排与差异；读取[阅读营产品知识](../../../knowledge/product/阅读营产品知识库.md)和[L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)中的适用版本正文；检索摘要不替代具体权益、安排与课程差异的核对。资料不足时使用[待核实问题跟进](../follow-up-unanswered-question/SKILL.md)。涉及效果质疑时关联[学习效果沟通](../address-learning-concern/SKILL.md)，投诉退费时关联[投诉受理与人工衔接](../handle-complaint-escalation/SKILL.md)；不要把“准备续费证据包”直接当成发送销售消息的许可。

## 交付与后续

根据权限生成老师草稿、家长图文报告或会议材料。只有真实生成并发送/交付成功，才能记录相应完成；没有图文或排版工具时保存正文、素材清单和待制作责任。发送前再次核对最新服务状态与家长新回复，撤销过时的结论或安排。

保存覆盖范围、采用的证据、每项结论的限制、实际交付结果和未解决事项。家长自主决定后续课程；是否续费、是否接受建议与学习效果分别记录，不能由材料已交付推定。

本能力是在[成长回顾材料](../prepare-growth-review-package/SKILL.md)基础上的后续课程规划扩展。沿用同一决策期材料事项、产物和交付计数；已有材料只补家长新问题所需的产品或课程说明，不再发一套证据包。面向不同受众核对证据新鲜度和可见范围，按既有授权与保留规则处理撤回请求，不自行设置期限。
