# 趣味知识互动

用当周所学让孩子轻松表达、解释，并有机会当一次家长的小考官。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[互动规范](../../guides/interaction.md)和[服务规则](../../config/service.yaml)。周五按四种互动形式轮换评估，主动互动每周合计不超过两次，核对暂停和近期督学并错峰；不是每天安排小测或另外增加补测制度。孩子已发来的答案优先回应。

新邀请按级别、书目、课程版本、课节读取当周[L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)的知识点和适用解释。回应旧题沿用原题、原课节及版本。缺少出题所需正文时先补资料，不凭相邻课节或模型常识冒充当周内容。

## 出题与点评

从当周新知识点设计 2–3 个趣味小问题，难度贴近孩子所学；用 60 秒内的语音出题，经家长私聊转达，接收孩子语音作答。题目可按对话节奏呈现，不强迫一次答完或答对才继续。

结合原题和课程依据点评讲解，具体肯定孩子的发现与思路，误解处给提示或解释。课程正文足以核实的事实题可说明正确之处，不额外要求必须存在机器评分接口；开放问题接纳有依据的不同回答，不强行判唯一答案。记录提示程度，不能把提示后的回答算成独立掌握。

点评后邀请孩子“也去考考爸爸或妈妈”，让孩子自愿当小考官；没有家长或孩子反馈，不推断亲子互动已发生。不能因孩子未完成这项邀请就反复催问。

## 接续与保存

老师用语音及时回应，遵循醒着时段两小时内的反馈目标。孩子另问课程内容时转[课程内容讲解](../explain-lesson/SKILL.md)，不以另开挑战题替代答疑。工具不足保留语音讲稿和待交付状态。

保存题目、知识依据、孩子实际回答、提示与点评及交付回执；适用表达可供[精彩表达记录](../highlight-expressive-answer/SKILL.md)和[阶段学情反馈](../review-learning-progress/SKILL.md)读取。完成实际答题交流和点评即可记录本次互动进展，亲子延伸单独记为已邀请或已反馈；题目发送、答题和能力判断不能合并为一个“已掌握”。
