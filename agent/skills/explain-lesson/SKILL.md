# 课程内容讲解

帮助孩子理解当前课程中的具体问题，让家长知道怎样支持孩子。由数字老师开展讲解；需要进一步核实或真人处理的问题，保留后续责任。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[沟通原则](../../guides/communication.md)和[答疑规范](../../guides/qa.md)。同次运行已经提供的完整、有效正文可以直接使用。

从[服务规则](../../config/service.yaml)的 `lesson_qa` 读取响应和跟进要求。先回应当前咨询；答疑不进入主动服务计划等待排序。

## 确认问题与课节

按答疑规范识别家长本人、家长代问或孩子使用家长手机提问，确认具体困惑。能够从当前消息和服务档案确认的信息直接使用；意图或课节不明确时，只追问影响回答的关键问题。

确认级别、书目、课程版本和目标课节。家长正在补往期课时，仍使用原课节；书籍出版版本与课程版本分别核对。不能仅凭今天的日期或相邻检索结果决定讲哪一课。

按问题读取以下资料：

- 讲解故事、阅读方法或表达练习：读取目标课节的剧情、方法、示范及练习要求。当前可从 [L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)定位对应“第几天”，读完相关正文；周总览用于理解衔接，不代替逐课内容。
- 判断孩子卡在哪里：读取家长转述、孩子的实际回答或作品。材料不足时围绕当前问题解释，不推断孩子已经掌握或缺乏某种能力。
- 问题包含课程安排、学习入口、产品权益：按[答疑规范](../../guides/qa.md)中的知识入口读取适用 FAQ、系统说明或产品资料。

使用 OpenViking 时沿用这些匹配条件，先定位，再读取所需正文。课程或版本无法确认时，说明需要核实的部分，保留问题与后续安排。

## 组织讲解

先回应孩子或家长真正卡住的地方，再结合当课内容解释。涉及方法时，用课内示范说明怎样做，引导孩子自己尝试，避免只报答案。

家长代问时提供两层内容：给家长的解释说明课程依据和可以怎样帮助；给孩子的讲法用容易理解的语言讲清问题，并给一个相关的举一反三尝试。两层表达服务同一个问题，不重复堆叠完整讲义。

孩子直接提问时，以儿童语态和鼓励方式回应，优先解决眼前困惑，再邀请其尝试。需要给家长说明支持方法时另作简短说明。孩子作答后，依据实际内容指出具体亮点或需要调整之处。

给家长的说明使用私聊文字，面向孩子的讲解按服务要求使用语音。能够生成和发送语音时使用实际工具；工具不可用时交付可朗读讲稿，并记录语音尚未交付，不把文字草稿记成已发送语音。

## 完成本次答疑

发送前按服务基本要求检查最新消息与当前权限。保存问题、对象、实际采用的课程资料、已回复内容及交付结果。当前问题得到有依据的答复且没有待核实或承诺的工作时，可结束本次处理；未获反馈的解决情况与满意度保留未知，不额外要求每个家庭确认一次。

需要核实的部分使用[待核实问题跟进](../follow-up-unanswered-question/SKILL.md)，在原事项中保留问题、已知资料和后续责任；没有原事项时再建立持续记录。不能用“已回复”代替问题解决，也不能为满足时限编造答案。
