# 首次课中题全对成就

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取该课全部课中题、孩子作答、评分规则与评分来源，确认课节、版本、作答次数、提示条件和此前全对记录。

## 判断与准备

核实该课题组全部答对且属于本服务范围的首次达成。某一道答对、达到及格标准、一次打开记录不能替代题组全对；历史不完整时可以描述本次全对，不宣称“首次”。不按每道题重新创建一次首次成就。首次数值范围以已确认班期/课程规则为准，范围不清时保留待核实责任。

按“全对成就解锁”组织情感开场、全对事实、可用对比锚点和理解表现解读。准确保留提示、重试或成人帮助条件；提示下全对仍可如实鼓励，但不能写成独立满分或稳定掌握。结合具体题目说明孩子在哪里理解了故事，不只泛泛表扬。

## 交付与后续

首次达成评估1次，通过家长私信交付图文卡。此服务不自行颁勋章；若孩子提出课程疑问，接续[课程内容讲解](../explain-lesson/SKILL.md)，保留已存在的成就事项。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
