# 阶段学情反馈

让家长看见孩子这一阶段的具体学习表现、已有进步与下一步支持方法，也让孩子获得有依据的鼓励。数字老师汇集材料并按适用模板准备图文报告，保留家庭对后续学习安排的自主决定。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)，以及[服务规则](../../config/service.yaml)中的 `learning_progress_review` 和 `contact`。

先明确反馈对象、起止日期、时区、相关书目与课节、家长关注点和本期已经交付的反馈。月度节点按月度范围评估；家长或老师指定一周时就回顾这一周，不将其写成整月结论。仅需回答一个具体问题时，围绕问题组织反馈，不强制输出完整月报。

## 汇集本阶段材料

读取本阶段已保存的高光卡、互动素材和金句，以及对应的课程完成记录、作品、作答或测评。核对记录覆盖的时间与同步情况；没有现成高光卡时可以读取相关原始记录，不为了凑齐素材生成一组未经核实的高光。

按级别、书目、课程版本与课节读取相关学习目标和方法。当前可从 [L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)定位对应课日及周总览；OpenViking 检索后仍需读取支撑判断的正文。需要了解练习要求时可读取[阅读方法练习](../practice-reading-method/SKILL.md)，但方法要求本身不证明孩子已经做到。

将每项判断与具体材料对应：完课与打卡支持参与描述；理解、复述、表达或迁移需要作品、回答等证据。引用孩子原话时核对语境与转写，说明发生的课节或时间。比较前后变化时，检查任务、难度和支持条件是否可比；没有可比材料就描述本次表现，不编造进步幅度。

## 形成有依据的反馈

按共用规范组织自然的开场、具体事实、可用的对比锚点和能力解读。月度报告应覆盖有材料支撑的本月金句、进步对比及能力维度表现；某一部分缺少证据时，明确资料范围并缩小结论。

家长已提出关注点时，先用相关证据回答。例如询问“学的方法会不会用”，就展示孩子在哪次实际表达中怎样使用方法，而不只列完课数量。需要接住焦虑或失望时，读取[沟通原则](../../guides/communication.md)。

建议要能由家庭实际尝试，说明可以继续什么、下一次练习什么，以及家长怎样支持。需要方法练习或补课安排时，可关联[阅读方法练习](../practice-reading-method/SKILL.md)或[补课规划与跟进](../plan-makeup-learning/SKILL.md)，不因写出建议就替家庭形成新约定。

## 交付与后续

月度服务通过家长私聊交付图文报告。使用实际可用且适用的模板与生成工具；缺少图片或排版工具时交付报告正文、配图建议及可用素材，标明图文成品尚未完成。发送前核对本期是否已经交付和当前状态，避免重复推送同一份反馈。

已知部分可以先交付；如果某份资料对家长当前问题必不可少，记录缺口和补齐责任。需要他人核实的事实问题可使用[待核实问题跟进](../follow-up-unanswered-question/SKILL.md)接续，不把没有作品当成孩子能力不足，也不为了补齐报告强行联系家庭采集无关材料。

保存实际采用的材料、报告覆盖范围、结论及其限制、交付结果和剩余工作。只有本次约定交付的内容实际完成且没有待补齐责任时，才结束该反馈事项；家长是否满意、孩子是否进步和是否续费分别依据真实反馈与记录判断。
