# 本周学习收尾

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)和[服务规则](../../config/service.yaml)。按班期课表核对本周全部应上课节、当天课节、完课状态、同步时间、家庭消息、暂停、约定与近期触达。

仅当本周只缺当天一节且其余均已完成时形成候选，命中时一次；未解锁的未来课节不能视作已完成，昨日欠课或多节欠课不适用。其他缺课关联[补课规划与跟进](../plan-makeup-learning/SKILL.md)或[周末补课安排](../plan-weekend-makeup/SKILL.md)。已有有效等待安排时保留原事项，不重复催促。

读取当天课节真实亮点，给家长私聊说明“还差今天这一节就完成本周课程了”和可选择的安排，嵌入给孩子的冲刺口信。“10 分钟就能完成”只有当该课实际时长或剩余任务支持时才使用，否则不承诺耗时。

发送前重查状态、暂停、约定、新消息和有效频控。与其他补课提醒或周度回顾适合合并时保留各自目标，并按原课节记录跨动作次数；同一学生、班期、周范围与目标课节不重复触达。

保存范围、依据、草稿、操作号及回执。按约定或明确复核条件核实实际完成；无具体核验时刻时保持未知，不自定联系时间。送达不等于完课。家庭提出暂停或说明困难时更新原事项；实际完成并无其余本目标责任时才结束收尾事项。
