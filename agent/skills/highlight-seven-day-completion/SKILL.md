# 七日学习成就

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。取得班期、时区、7日统计窗口的起止日期、5天应学课程及完成数据。窗口起点尚未确认时先核实，不自行设为滚动周或任意自然周。

## 判断与准备

核对7日内完成5天课程，而非连续7天学习、7次打卡或打开课程。补课仍归原课节，多次学习同一课不能重复计为不同课程日。保存各原课节、完成时间与同步时间；数据不足时保留待核验。同一学生、班期和已确认窗口的本成就达成评估1次，重复事件续办原事项。

形成“7日完课”图文卡：以一周坚持的真实记录为事实，选择第一周与起步时可比较的记录作为锚点，解释这是阅读习惯培养中的一次实践。没有起步基线就写本次参与表现，不虚构前后进步，也不据此断言习惯已经形成。

## 交付与后续

通过家长私信交付图文卡；后续节奏变化按实际需要另接补课或学习支持，不因窗口内存在休息日撤销已符合口径的成就。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
