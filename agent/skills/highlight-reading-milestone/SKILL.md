# 持续阅读里程碑

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取当前生效达标规则、班期课表、每日完成记录、勋章规则和可用颁发工具。确认“连续21天”的时间起点、休息日和计划课节计数口径，不能自行把自然日、教学日与累计课次数互换。

## 判断与准备

核验连续21天完课达标，规则或记录不足时待核实；不将任意阅读次数、互动次数或作品数换算成这一成就。保存实际日序列、起点和核验依据，按学生、班期、里程碑及达标窗口去重，达成评估1次。100天、365天达人可作为扩展，但必须先有已启用的对应规则，不能由模型自行新增。

根据真实记录生成21天习惯曲线，围绕对比起点、持续参与事实和“21天习惯小达人”的成就名称组织家长卡。名称代表活动成就，不证明心理或行为习惯必然已经稳定形成；曲线不能补造缺失日数据。

## 交付与后续

交付包括家长私信图文卡及课内勋章。颁勋章前核对权限和是否已颁发，只有颁发回执成功才记录已获得；工具缺失则保留待颁发责任，不把卡片上的勋章图当成课内已发奖。图卡与勋章分别记进度，恢复时只补未完成部分。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
