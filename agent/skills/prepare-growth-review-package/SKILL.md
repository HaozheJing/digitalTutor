# 成长回顾材料

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。确认本次决策期范围、老师或家庭需求、家长关注点、材料覆盖期间、书目与课程版本、交付受众以及此前报告。

进入决策期只意味着评估机会，不自动授权销售联系。决策期按已确认安排交付1—2次，重复触发关联同一材料事项；需要超过现有安排时先核实，不自动增加次数。与[成长与续费材料](../prepare-renewal-evidence/SKILL.md)共享这一事项和既有产物，后者仅补充后续课程规划说明，不重复采集或另发一套证据包。

## 汇集成长证据

读取全程高光卡、真实颁发的勋章、月报、互动金句、作品、作答和学习数据。保留每项材料的来源记录、发生与核验时间、课节或书目、课程版本、成人帮助与提示条件和可见范围；孩子原话与老师解读分开。旧高光的结论需回到对应证据，不能层层转述变成新的证明。

按时间编排学期成长报告合集，保留高光时刻、数据、作品，以及家长最关注的变化。完课数据只支持参与描述；能力维度需要作品和可比的前后材料。缺少勋章、金句或比较基线就如实说明，不为了凑齐成长故事造证据。

## 一封信与沟通材料

可用一封信串起真实成长：具体的开场、代表性学习经历、孩子原话或作品、可核实变化、仍需支持的部分和下一步可选建议；附有材料的报告合集。面向老师准备证据位置及沟通要点；面向家庭使用易懂的解释，保留家庭自主决定，不暗示购买才能保住既有权益。

交付形式是私聊材料或会议沟通资料，按实际约定生成正文、目录和素材。若家长只问一个阶段问题，转[阶段学情反馈](../review-learning-progress/SKILL.md)围绕问题回应，不强制进入决策期材料流程。投诉、暂停或未解决问题仍保留各自责任，不能因材料完成而关闭。

## 交付与接续

发送前读取最新状态、近期触达、授权和已有产物，撤销过时结论并避免重复发送。生成、保存、交付和回执分别记录；工具不足时交付可用正文和素材清单，保留待排版或未完成部分，不能称成品已交付。发送结果未知时查原操作。

只有本次约定材料实际完成并交付、没有剩余制作或核实责任，才结束材料事项；送达不等于阅读、满意或续费意愿。材料按既有授权和保留规则处理，撤回请求续办到原素材与产物，不自行设置统一保存期限。
