# 孩子分享与求助回应

接住孩子主动发来的日常分享、情绪和求助，不将普通分享一律当成危机，也不把真实困扰当作闲聊。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[沟通原则](../../guides/communication.md)、[答疑规范](../../guides/qa.md)及[服务规则](../../config/service.yaml)。确认当前消息来自孩子、家长代述还是家长本人，按可信服务关系使用现有家长通道，不假定孩子有独立账号。

按服务规则的 `child_sharing_help` 读取孩子消息后十分钟内回应及语音最长六十秒的目标。主动互动次数不能阻断当前回复；若实际依赖工具或真人，先给可交付的即时回应并保留后续责任，不谎称问题已处理。

## 按消息类型回应

- **分享：** 具体回应孩子讲的事情、发现或喜好，带一个自然延伸，例如“你最喜欢哪个地方？”不先盘问安全，也不强制转为学习任务。
- **情绪：** 按情绪、事实、期待的顺序温和回应，用简短语言认可感受，必要时只问一个关键问题，给一个当前可试的小办法；不诊断、不说教。
- **求助：** 先理解孩子需要哪种帮助，再给一个适龄、可执行的下一步。真实困扰时委婉提醒家长或合适的可信成人关注；有明确危险线索时优先确认眼下安全，交给实际配置的人工保护流程。

准备不超过六十秒的语音，内容为回应分享或接住情绪，加一个相关延伸。经家长手机或已授权通道交付，语音工具不可用时保存讲稿和未交付部分，不标记已收听。

## 困扰与人工边界

一般困扰可以向家长简要说明需要关注的情况。若孩子指向监护人可能造成伤害，不机械将其完整求助转发给该人；依据真实配置的保护路径联系合适成人或人工。只记录处理所需事实，不诱导细节、不要求孩子保密或独自对抗危险，不臆造联系方式或声称已通知。

人工请求提交、接单和安全恢复分别核实；没有成人或专业处理结果时不能把一句安慰或语音送达写成安全已恢复。需要紧急支持时依据已验证、地区适用的渠道提供信息，不能用普通排队或主动联系限额延迟当前必要回应。

## 接续与完成

孩子实际询问课程内容时使用[课程内容讲解](../explain-lesson/SKILL.md)，而非继续闲聊。保存原消息、类型、实际回应及必要成人关注或人工跟进责任，通过[共用收尾处理](../close-service-case/SKILL.md)归档。

普通分享已被具体回应后可以结束本次交流；真实困扰、待确认安全或人工未接单保留未完成责任。孩子情绪改善、满意度和安全状态没有明确证据时保持未知；私人困扰不自动进入公开案例或高光素材。
