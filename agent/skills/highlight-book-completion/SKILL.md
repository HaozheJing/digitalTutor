# 完书成长纪念

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取书目、课程版本、全书课节清单、实际完成及书架点亮记录，并读取书内真实表达、共鸣金句和已有交付历史。

## 判断与准备

逐课核实全书完成，不以最后一课完成、买书或下载书籍替代；补课归原课节，异常补记与同步延迟先核验。核对这是学生首本书还是后续书首次完成：“首本书”与“每本书首次”的服务范围尚待统一，未确认时不自行扩大发送范围。按学生、班期、书目、版本及对应完书成就去重，同一书目的首次成就评估1次。

组织“第一本书点亮”或与已确认范围相符的完书卡：书名、完成事实、孩子在书中最有共鸣的一句、可核实的阅读坚持表现。只在确为首本时使用“第一本”；金句必须有实际记录，缺失时说明仅有完课事实并保留确有必要的资料责任。解读坚持读完的过程，不单凭完书宣称耐力或理解力已稳定提升。

## 交付与后续

通过家长私信交付图文卡。后续书目或课程由家庭选择，纪念不自动转成续费或新课程约定。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
