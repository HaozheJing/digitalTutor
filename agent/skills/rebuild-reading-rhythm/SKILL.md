# 重建阅读节奏

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)，以及[服务规则](../../config/service.yaml)中的 `supervision`、`makeup_learning` 和 `contact`。确认学生、家长服务关系、当前时间和时区、运行模式及可用工具。

核对上周应上课节数、实际完成节数、本周已解锁课节、完成数据的更新时间、已有补课或暂停事项和近期触达。“上周参与偏低且本周零完课”只是评估条件；偏低阈值尚未给定时保留待确认，不编造百分比或节数。数据未同步或时间范围不明时先保留待核验，不直接发起提醒。每周三或发现该情形时可评估一次，同一周同一目标不因两个入口命中而重复联系。

## 判断是否适合重建

- 上周完成偏低且本周还没有完成记录时，关联同一家庭已有事项，判断是等待、暂停、补课、主动咨询还是需要重建节奏。
- 家长已经说明出差、生病、考试等原因并给出有效安排时，先按原约定等待，不用本能力覆盖暂停或再次催促。
- 同日已有答疑、补课核验或其他必须回应的消息时，先处理即时事项；只有确认本次联系必要且符合频控，才把节奏建议加入待处理队列。
- 触发不等于发送。检查近期开口次数、家长可用时间、暂停范围和已有未结束联系，必要时合并为一条消息或保留内部待办。

## 设计小目标

先描述已核实的事实，例如“上周完成了 X 节，本周目前还没有完成记录”，不使用责备或同伴比较。结合本周课表设置一个明确但可调整的小目标，默认可以从“先完成本周前 3 节”或一个双方约定的起点开始；不要替家庭决定具体日期、时刻或孩子一定能完成。

给家长的私信说明小目标、可用的学习入口和需要家长支持的一件小事，同时嵌入给孩子的鼓励口信，例如“我们先完成三天小挑战”。没有真实课节、入口或昵称时不编造。遵守[沟通原则](../../guides/communication.md)中已发布的表达边界；本能力不把文字草稿记为已发送。

如果需要安排缺失课节，关联[补课规划与跟进](../plan-makeup-learning/SKILL.md)，保留本次重建目标与补课目标的关系，不能把“定了小目标”写成补课已约定。

## 核验与收尾

发送或建立待办后，保存目标、覆盖的课节、事实时间范围、依据的数据更新时间、实际交付结果和下一次核验条件。周三或“发现即一次”的时间点只是评估入口，不能凭配置声称已经建立定时任务。

到核验节点先读取最新完成数据、同步时间、家长回复、暂停和其他事项：完成部分按事实记录并可继续鼓励；没有完成时了解新原因、调整小目标或按生效规则转入补课/人工协助。没有明确的升级时点，不自行添加“再等几天就电话联系”。

一次消息送达不代表阅读节奏恢复。只有约定的目标已实际完成、结果已保存且没有待处理责任时，才结束本次重建事项；家长未回复、工具结果未知或满意度未知都分别保留。
