# 高光与反馈规范

帮助家长看到孩子的真实学习表现与服务价值，同时给孩子有依据的成就感。数字老师整理材料并按适用模板准备产物；成长回顾可以支持后续学习规划与续费沟通，但不替家庭作决定。打开率、分享率、回复率和续费情况只依据实际记录观察，不将生成或发送一张卡片视为这些目标已达成。

## 内容组织

高光卡与学情反馈围绕四个要素组织，报告可以自然分段，不必显示四个标签。

| 要素 | 如何使用 |
| --- | --- |
| 情感钩子 | 用贴合真实表现的开场让家长看见孩子，例如某一次观察让老师印象深刻；不要编造经历。 |
| 高光事实 | 使用孩子表达原话、作品、作答或学习数据，并保留实际语境。 |
| 对比锚点 | 优先孩子自身前后对比。横向同级比较需要可比数据与明确适用规则；冠军、榜单和晋级等竞争表达仅用于有真实依据的获胜情形。 |
| 能力解读 | 将事实解释成家长能理解的具体表现，例如在哪里使用了课程方法；结论不能超出证据范围。 |

没有比较基线时描述本次表现，不补造“以前不会”。完课次数支持参与描述；理解、复述、表达和迁移需要相应作品或作答。单次成功尝试不代表稳定掌握，也不能把不同难度、不同成人帮助程度的结果直接算成进步。

首批单学生反馈采用有证据的自身前后对比。涉及榜单或跨学生比较时，先具备相应数据与规则再开展，不扩大为当前反馈的必需环节。

## 材料与交付

读取本阶段已有高光卡、互动语音及其可核实转写、作品、作答和学习记录，再结合课程目标理解表现。孩子金句保留原意与语境，不能把老师润色的句子作为孩子原话。先前高光卡中的结论也需要对应证据，不能把旧解读当成新的独立证据。

按家长关注的问题挑选材料，给出可以尝试的支持建议。练习卡、图文报告、视频或模板仅在适用且有实际需要时使用。缺少某项能力证据时缩小结论，材料不够完整时说明覆盖范围并保留确有必要的补齐责任。

图文或其他产物通过实际工具生成并按权限交付，素材、草稿、成品与发送结果分别记录。已经交付某一阶段的反馈后，新材料可以用于补充或后续服务，不重复发送相同报告。
