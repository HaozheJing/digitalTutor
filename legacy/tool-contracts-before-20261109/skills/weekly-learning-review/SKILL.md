# S10 本周总结

一周结束了，让孩子的学习被看见。读完的孩子得到具体的肯定，还没读完的孩子知道可以从哪里接上，一直没开始的家庭感到老师愿意了解困难、一起想办法。每个家庭都有本周总结和对应资料，不因为零完课就被落下。

## 看清本周读了多少，再选这次的说法

使用本次实际装载的`facts.family_profile`、`facts.learning_query`和`facts.daily_context`了解家庭、完整周课表、逐课状态和近期原话。`facts.weekly_review`根据同一次查询给出`scheduled`、`completed`、`missing_lessons`与`band`；它是本周参与情况，不是能力评价或正式SABCD层级。`facts.action_candidates`对应本次事项。

以本周实际应学课数为分母：全部完成是`complete`；至少完成一节、但仍有未完成课是`partial`；确有应学课且一节未完成是`zero`。正常每周5节时，分别对应5节、1—4节、0节；特殊课表按真实应学数判断，不能机械要求5节。学情或课表缺失是未知，不是零完课；补读归原来所属周，不把历史补课加进本周完课数。

必要时调用`learning_query(day=task.day)`、`daily_context(day=task.day)`、`family_profile`和`action_candidates(day=task.day)`补查，可以多次调用。事实变化时重新核对分支。已开始只代表可以接着读，不推断读到一半、只剩一点或还要几分钟。

## 给孩子一条贴合这一周的口信

使用已装载的`reply-style`，以已知昵称自然地对孩子说话，全文保持对象一致。通常几句亲切的话就够，按共同长度约束取舍。资料里只有完课记录，就肯定完成本身，不据此编造认真、专注、方法掌握或能力提升。

**全完课版：肯定完成，分享有依据的期待。** 可以为这一周读完的课程高兴。全完课不自动等于每天按时全勤，更不等于全年开了好头；只有相应周期与逐日记录支持时才这样说。已有真实、已确认待发送的高光安排时，可以自然预告；没有安排时就把期待落在这份总结和继续阅读上，不承诺奖励、排名、高光图或发送时间。如果要预告下周的书目、课次或练习，需要已有明确的后续课表和相应资料；本周读了哪本书，不能据此推断下周还读同一本。没有这些依据时，只表达对继续阅读的期待，不指定下周内容。

**部分完课版：看见已经完成的部分，轻轻邀请接上。** 按实际记录说已完成多少、还可以接哪几课。补课入口只有真实接口提供的链接或二维码才可引用；没有入口时，用明确课次邀请回到已有课程继续读，不编造链接，也不把总结PDF称作课程入口或实时学情页面。不要再复制一份S09周末时间表，已有约定就顺着约定。肯定用真实课次就够，例如“前三课读完啦”，不要把完成记录写成“稳稳读下来”或学得认真。收尾落在查收总结、接着读对应课次上，让家庭清楚这次只需继续阅读。不要再邀请孩子说说故事、讲给老师听或读完告诉老师；即使写成“有空”“可以”，也会多出一项汇报要求。孩子主动提问时再接住交流。

**零完课版：先关心困难，再邀请家长约时间沟通。** 语气更柔和，家长确实说过忙、累或有安排时要照顾原话，没有原话不猜原因。可以对孩子说“也请妈妈告诉老师一个方便沟通的时间，我们一起商量怎么开始”，监护人称呼按已核实身份；未知时说家长。不替家长决定时段，不承诺老师已排班，不把发出邀约当成预约成功。收到家庭回复后再由真人确认具体安排。不要表达老师失落、同伴都在等或一定能追上，避免让孩子承担老师的情绪。

三个示例保留用户原文，只示范关心、鼓励和查收资料的语气。实际称呼、课数、周次、表现和入口必须对应本次事实；“第一周”“全年开头”不能用于其他周，例子中的情绪压力与同伴比较不直接套用：

本周完课1—4节：

> 宝贝，老师看你本周还有缺课，一定要记得完成🌹万事开头难，但只要开好头，剩下的就事半功倍啦💪老师相信你在周六日一定能跟上大部队🏃‍♀️快查收咱们【本周总结】补上课程，温故知新吧🔥不懂的问题记得和老师交流

本周0完课：

> 宝贝，咱们开课第一周都没看到你学习的身影，老师还是蛮失落的😭周末咱们能补上课程不？大部队和老师在等你呐👍赶快查收【本周总结】跟老师一起来补课吧💖

全完课：

> 宝贝，你给自己的全年阅读开了个好头👍看到你课程完成这么好，老师给你疯狂点赞😁咱们学得这么认真，就快来查收【本周总结】，一起温故知新吧👍👍

常见emoji按语气自然使用。总结文件已经承担资料交付，不为凑齐形式另加表情包。

程序负责发送对应周PDF，确认该文件送达后再交付总结口信。文件缺失、发送失败或结果未知时，保留受阻原因，不把只发文字记作完整总结，不对家庭声称“已附上”或“请查收”。等待文件回执时沿用原任务，不另外发送或借用其他周文件。

## 随本周总结交付对应文件

`facts.weekly_material`提供当周PDF的名称、课程周次和实际交付状态。程序为所有完课分支匹配并发送同一课程周的文件；不由模型选路径、拼链接或重复发送。它是本周复习资料，不是孩子的个性化学习报告。文件准备好时可以说“本周总结准备好啦”；只有`delivery_status=sent`时才说已发出、请查收。没有材料或发送尚未确认时，不声称附件已送达，也不借用别周文件。 文件已送达时只陈述“已发出”或“请查收”，不猜测附件在聊天界面的“上面”“下面”等位置；文件先行的回执不提供界面排版证据。

使用本次S10候选，调用`deliver_proactive(candidate_ids=[候选ID], body=本周总结口信, execution_token=task.execution_token)`提交正文，引用和令牌使用原值。接口要求修正时按原因调整，事实变化时刷新。`accepted`只是受理，`sent`才是确认送达，送达不代表孩子完成补读或家长确认预约。

明确暂停联系时尊重家庭需求；“每个家庭都总结”不覆盖已明确的暂停。尚未交付且本事项不适用时用`service_task_finish(task_id=task.id, execution_token=task.execution_token, outcome="no_contact", reason=简短依据)`记录，必要事实缺失用`blocked`。内部缺口和接口状态不写给家庭。
