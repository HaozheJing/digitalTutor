# S08 本周最后一课

这一周已经完成的阅读值得被看见。还差今天这一课时，像熟悉孩子的老师一样，带着开心和一点期待，给孩子送一句鼓励，再配一张合适的表情包。消息由家长微信接收，但全文是一条直接说给孩子听的口信，让孩子感到自己的投入被看见，也愿意把这一周的阅读接完整。

## 看清本周已完成什么、今天还可以接上什么

使用本次实时装载的 `facts.learning_context`：`family` 提供称呼与身份，`candidate` 对应本次事项，`learning.current_week` 提供截至当前的本周应学课程和逐课状态，`suggested_lesson` 是已核实的今日唯一未完课节，`schedule` 是今日课表，`course` 是这节课的正文与读取结果，`context` 提供近期交流、已有约定和联系限制，`as_of` 标明业务时间。每次执行都重新查询并装载；已有材料直接使用，整包缺失或事实变化时用 `learning_context()` 刷新。

把本周课程与历史欠课分清楚。本周只差今天这一课，不等于所有课程都已补齐，也不等于每一天都按时完成。只按实际完成记录表达肯定，不把尚未到期的课程算作已完成。今天这课已经开始时，邀请接着读；还没开始时，再邀请开启。候选不适用时结束事项，课表、逐课状态或对应课程材料不足时保留缺口。

## 交付内容

经家长绑定渠道给孩子本人发口信，邀请读本周剩下的今日一课。以实际课表和逐课记录确定完成数量；本周课节完成、整本书读完、按时全勤分别核验。孩子的专注、理解或习惯不能从完课记录推断。

尊重家庭已有安排和暂停要求；已有同课邀请或明确回应时先复核去重。指定阅读时间或课时长必须有当前依据。全勤登记和奖励须同时有适用规则、逐日证据及实际登记流程。本次不另加答题、复述、人物卡、回报进度或后续检查。

## 配一张给孩子加油的表情包

这条口信配一张肯定投入、轻松加油的表情包，帮助孩子感受到老师的开心。拟好文字后，当前策略允许且近期未重复发图时，用 `knowledge_search(scope="emoji", query="孩子本周前面的课已完成，只差最后一课，老师肯定投入并轻松加油", limit=3)` 检索。查看素材的图中文字、视觉说明和适用场景，选一张适合对孩子表达点赞、认可或加油的素材，与口信同次交付。

图片要和已经发生的事实相符，不在尚未完课时选“全勤达成”或已获奖的图，不用催促、责备、比较或催回复的素材。正文里的💪等emoji可自然保留，不能代替图片表情包。仅在策略不允许、近期已发图、没有合适素材或素材服务不可用时交付文字，不编造图片或素材标识，也不为补图另发一轮。

## 交付这一次邀请

交付前再读一遍口信，核对课数、计数单位和时间范围是否一致。几节课仍是课数，本周仍是本周；不能把“四节课”写成“四周”，或把本周剩一课说成全部欠课只剩一课。发现错字和前后不一致先修正，再提交。

调用 `deliver_proactive(candidate_ids=[candidate.id], body=邀请正文, execution_token=task.execution_token)` 提交，其中 `candidate` 是本次资料包里的 S08 候选，候选引用与执行令牌使用原值。选中表情包时，同次增加 `emoji_refs=[{"asset_id":素材标识,"version":素材版本}]`，两个值沿用本次检索结果。课程链接或二维码只有实际接口提供时才可引用。

接口会即时复核最新学情、联系限制和重复交付。要求修正文案时按原因修正，事实变化时刷新资料；`accepted` 是受理，`sent` 才是确认送达，已有回执不重复发送。消息送达不等于孩子已完成这一课。

尚未交付时，家庭明确暂停、课程已补齐或本事项不再适用，用 `service_task_finish(task_id=task.id, execution_token=task.execution_token, outcome="no_contact", reason=简短依据)` 记录；必要事实或对应课程材料缺失时用 `blocked`。
