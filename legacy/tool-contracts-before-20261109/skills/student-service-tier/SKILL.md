# 用正式分层事实选择已定义的服务

用户说明孩子层次可由接口读取，合法层级为 S、A、B、C、D。《最新数字员工服务动作打样》只写“按分层”“全分层”等，没有定义各层含义、阈值、语气、权益或动作差异。因此先读取，不自创评级或待遇。

## 读取与核对

- 调用 `student_tier`，按工具定义传入当前已绑定孩子/课程所需参数。不要用昵称替代UID，不跨孩子读取或使用其他家庭的等级。
- 只把有来源、时间及明确适用对象的 S/A/B/C/D 结果作为已知分层。按返回状态识别 unavailable、unknown、invalid 或过期/不适用；缺字段、接口失败或层级不合法均保留未知，不默认D，不从连续缺课推断C/D。
- `level` 是服务分层事实，不等于能力诊断、学习成绩或用户价值判断。课程 L2/L3、排行榜档位、服务升级层级与 SABCD 独立，禁止混用。
- 读取结果只用于当前决策，不自行改写档案、记忆或升级/降级。需要更新等级必须有正式写入接口和明确授权，本 Skill 无此权限。

## 使用范围

分层本身不足以支持不同的消息内容或额外服务。只有接口或已发布政策同时给出适用动作、各层规则、版本和有效范围时，才按该规则分支，并记录依据。不能凭 S 猜“优秀”、凭 D 猜“高风险/沉默”，不能自动增加低层催课、高层福利或额外续费消息。

暂缺各级规则时，记录“已取得等级，分层策略待配置”，按已有明确学情和对话偏好执行通用服务；档案等级未知时记录缺口，仍可回答不依赖分层的事实问题。不能为了补齐等级向家长追加无关追问。

面向所有层级同样保留准确事实、尊重意愿、真实交付和防打扰要求。层级不得绕过暂停、时效、联系方式限制、图片接口、一次性高光或候选资格，也不得向家长展示未经解释的内部标签。

## 例子

| 已知情况 | 正确处理 | 不允许 |
|---|---|---|
| 接口返回 A，当前学情显示本周缺两课，未配置A级策略 | 用已核实缺课事实和通用补读规则判断；内部注明分层策略缺失 | 擅自认为A级不需提醒或可突破额度 |
| 孩子课程为L2，分层接口未配置 | 课程仍是L2，SABCD为未知 | 把L2映射为B或因缺课映射D |
| 接口给出S，但对象或课程不匹配 | 不使用该结果，记录对象不匹配 | 套用另一孩子的S级策略 |
| 接口给出D，且家长明确今天别提醒 | 遵守当天暂停并保留理由 | 以D级“高风险”绕过暂停 |
