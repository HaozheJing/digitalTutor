# 往期课程补读

## 核对适用情况

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)和[服务规则](../../config/service.yaml)。核对学生、班期、当天新课已完成的事实、累计缺失的原课节与课程版本、完课同步时间，以及家庭消息、暂停、请假、补课约定和近期触达。

当日新课尚未完成不使用本主动入口；历史缺课不限定在本周。每日可评估，不能每日必发；同一节课跨补读动作合计最多两次每周，周范围与全局计次按实际生效配置。已有同一目标事项时接续其记录，有有效约定时等待，不能重开事项绕过频控。连续缺课、已说明困难或需要协商安排时关联[补课规划与跟进](../plan-makeup-learning/SKILL.md)。

## 整理内容和入口

读取原缺失课节的适用正文，说明补上哪节可以接上内容。给家长的私聊先肯定今日已完成，再列出实际往期缺课数与可补课节；可以按课程顺序推荐从一节开始，但不能隐去其余欠课责任。嵌入给孩子的鼓励口信，例如“今天完成得很好，邀请你当追进度小英雄，把这段故事接起来”。

查询真实补课链接，并在工具支持时生成对应二维码。核对入口所指班期、版本和课节；没有真实入口不得编造链接或二维码。链接可用、二维码生成不可用时，可按授权提供有效链接并明确二维码未交付；都不可用时保留待补入口和草稿，不把二维码已发写入结果。

## 执行与接续

发送前重新检查学习更新、消息、暂停、约定和有效频控；与其他补课服务适合合并时分别计入涉及课节的触达记录。按学生、班期、原课节与已有事项识别重复，不因更换入口、名称或渠道重置次数。

保存累计缺课范围、目标课节、材料与入口、草稿、操作号及实际回执。发送未知时先查原操作，不重复发送。家长了解入口、形成补课约定和实际补完分别记录；某一课节完成只结束该课节责任，其他缺课继续保留。
