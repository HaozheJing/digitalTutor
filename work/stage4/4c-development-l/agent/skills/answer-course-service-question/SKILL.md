# 课程服务答疑

用适用的标准答案解决当前问题，区分通用规则与家庭实际状态。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[沟通原则](../../guides/communication.md)、[答疑规范](../../guides/qa.md)和[服务规则](../../config/service.yaml)。按答疑五步识别提问者、意图、情绪、处理路径与所需知识；意图已明确不重复追问，不明时一次确认一个关键问题。

当前可从[常见问题资料第4.6节](../../../knowledge/service/【数字员工】服务动作打样.md#46-知识库)读取适用问答全文；产品定位、权益与差异读取[阅读营产品资料](../../../knowledge/product/阅读营产品知识库.md)。OpenViking 接入后沿用相同范围读取正文，不只看摘要。

## 核对并回答

按问题核对课程级别、产品和有效版本；具体操作还需匹配用户端版本。一般说明只取必要信息，不要求每条通用问题都先查个人订单。个案的开课、权限、物流或执行状态须查询该家庭真实记录，FAQ 示例中的“已处理”不代表当前已执行。

资料命中且适用时，给出简洁答案、必要操作步骤及一句相关的主动延伸，例如“如果还是看不到，可以告诉我停在哪一步”。按服务规则的 `course_service_qa` 读取十分钟内首次回应目标，记录实际响应，不将该目标说成问题必然在十分钟内解决。

面对孩子用儿童语态和语音；家长代问保留给家长的解释与给孩子的讲法。解释课程内容时转[课程内容讲解](../explain-lesson/SKILL.md)，效果疑虑转[学习效果沟通](../address-learning-concern/SKILL.md)，退费申请或投诉转[投诉受理与人工衔接](../handle-complaint-escalation/SKILL.md)，接续原问题而不另建重复事项。

## 缺口与后续

资料未命中、版本冲突或规则适用性不明时使用[待核实问题跟进](../follow-up-unanswered-question/SKILL.md)。新版资料只有明确替代且适用于当前家庭时才能覆盖旧规则，不能仅按发布日期挑一条方便的答案。可先回答不受缺口影响的部分。

按实际权限查询、建草稿或执行；未知回执先查原操作。只有真实工单提交和接收证据才能写已提交或已接单，工具不存在时保留待办和实际可用入口，不虚构工单号、负责人或时限。

答案已交付与问题解决分别记录；操作指导未获结果反馈时保留结果未知。通过[共用收尾处理](../close-service-case/SKILL.md)保存问答、知识依据、未决责任和已知反馈，不把归档或沉默当作满意与解决。
