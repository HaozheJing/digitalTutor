# 投诉受理与人工衔接

及时回应退费或投诉诉求，数字老师准备材料并衔接真人，真人以电话为主处理；不以自动回复代替人工处理。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[沟通原则](../../guides/communication.md)、[答疑规范](../../guides/qa.md)和[服务规则](../../config/service.yaml)。适用服务规则从[常见问题资料第4.6节](../../../knowledge/service/【数字员工】服务动作打样.md#46-知识库)及[阅读营产品资料](../../../knowledge/product/阅读营产品知识库.md)读取，核对版本与该家庭适用条件。

只用适用规则说明流程；FAQ 中的示例价格、退款数额、资格或到账时间不自动适用于当前家庭。明确退费申请即进入人工衔接，不要求先证明投诉成立或先完成挽留沟通。

## 先回应，再整理事实

先接住情绪和期望，保留家长的原意；已知诉求不反复要求复述。核对相关学情档案、订单或服务记录、历史沟通和执行结果，按时间线整理已核实事实、家长主张及待核实部分。只读取此事项需要的资料，不收集无关家庭信息。

为真人准备材料包：相关学情档案、事实链、家长期望、已做处理、剩余问题及适用的可选方案。材料缺失标明缺口，不为凑齐材料而拖延受理；不删除不利记录，也不替真人承诺退费、赔偿或最终责任。

## 交接与续办

核对是否已有同一工单，按实际配置提交或更新原请求并路由到 L3 真人。电话由真人执行，记录家庭已提供的联系方式、方便时段及联系限制，不在无接单证据时说“老师马上给您打电话”。

提交、接单、沟通、方案批准与实际处理分开记录。真实渠道确认接收人和更新时间后再向家长说明安排；未接单或提交失败保留原请求和跟进责任，若结果未知先核对原操作回执，不重复建单。涉及儿童保护、隐私或其他紧急风险时走应用真实配置的对应人工路径，不都归为普通退费处理。

## 完成依据

保留工单号（若实际生成）、事实材料、负责人状态、下一节点与对客回应。交接成功仅完成交接步骤，投诉或退费是否解决需实际处理结果及尚存责任支持。通过[共用收尾处理](../close-service-case/SKILL.md)保存进展；家长未回复、真人已接单或材料已归档均不等于投诉已经解决。
