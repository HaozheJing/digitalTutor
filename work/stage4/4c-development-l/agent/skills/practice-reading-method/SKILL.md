# 阅读方法练习

让孩子把当周所学的方法或句式用出来，通过示范、尝试和点评增进理解与师生关系。由数字老师根据实际权限开展，孩子通过家长私聊接收语音并回复。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[互动规范](../../guides/interaction.md)，以及[服务规则](../../config/service.yaml)中的 `interaction`、`method_practice` 和 `contact`。

发起前查看本周所学课节、相关练习、已开展的互动形式、近期督学联系及有效约束，确认这次是否适合邀请。时间节点只是评估入口；轮换没有选中方法练习时，不因本 Skill 可用就另发一次。

若当前输入是孩子的新回复，优先回应，核对关联的邀请与练习，不把回复当成重新发起一次互动。

## 准备示范与句式卡

新发起练习时，按级别、书目、课程版本和课节读取当周方法、范例与练习要求。回应既有邀请时沿用原邀请的课节、方法、版本和要求，不因跨周改用当前周内容。当前可从 [L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)定位相应课日；需要理解周内方法衔接时再读取周总览。使用 OpenViking 时沿用这些范围，读取相关正文。

选一个当前适合练习的方法或句式，用“我用这个方法做了一次”的方式先示范，再邀请孩子“你也试试”。示范要能看出关键步骤，练习应让孩子有机会自行表达，不能把完整答案填好后只要求照念。

准备老师范例语音与句式卡。句式卡呈现本次使用的方法提示或句式骨架，内容与课程一致；已有适用物料就读取并使用。需要生成物料时使用真实工具，不能把讲稿、卡片文案称为已生成或已发送的语音与图片。

## 接住孩子的尝试

邀请发送成功后保留当前互动事项，等待孩子表达；当天发出邀请不代表整个互动已经完成。没有回复时不自行增加固定追问次数或结束期限。

收到回复后先确认它是在回答本次练习，还是提出新问题、分享其他事情。具体课程疑问可以使用[课程内容讲解](../explain-lesson/SKILL.md)回答；原练习按最新情况接续，不把另一条咨询计成练习完成。出现情绪时读取[沟通原则](../../guides/communication.md)处理。

听取实际语音或读取可核实的转写，结合本次方法做针对性点评：先肯定一个具体亮点，再给一个当前最有帮助的提升点，最后用语音回应。不要把一个回答扩展成多个纠错任务；无法听清或转写不可靠时，先确认影响点评的内容，不猜测孩子说过的话。

## 保存素材与进展

按互动规范保存孩子表达、可用转写、本次课节与方法、老师实际点评和交付结果。素材中的孩子原话与老师解读分开，适合的表达可以进入该学生的高光素材候选，供[阶段学情反馈](../review-learning-progress/SKILL.md)按需要读取，不因保存素材就自动发送另一份报告。

孩子完成本次尝试且老师已实际回应后，可以记录本次互动目标达成；不要据此认定方法已稳定掌握。只有草稿或工具尚未完成语音交付时，保留未完成部分；停止邀请或家庭未回复也不记作互动成功。
