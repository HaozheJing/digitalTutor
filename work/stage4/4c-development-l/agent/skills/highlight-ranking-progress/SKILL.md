# 学习榜单晋级

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取榜单档位与晋级规则、前后快照时间、对应范围、并列及新入榜处理和允许展示范围。

## 判断与准备

确认前后排名、档位和榜单口径可比，且符合有效晋档规则。记录晋档前后档位与实际变化，不把新入榜、排名数字变小或参与人数减少自动解读为晋档。没有旧档位证据时只保存当前事实，不发送晋级成就。晋级时评估1次，按学生、榜单和该次晋档事件去重，重复数据或同一事件多次上报续办原事项。

以“晋级”图文卡呈现前后档位、可核实的努力过程和努力得到反馈的解读；有作答或作品证据才进一步解释能力。发送前复核榜单更正，失效或不可比时调整旧草稿，不用进步话术掩盖降档或未知。

## 交付与后续

通过家长私信交付图文卡，只展示该家庭获准看到的本人信息，竞争表达不得羞辱其他孩子。家长因此焦虑或质疑时先使用[学习效果沟通](../address-learning-concern/SKILL.md)回应，不继续推送榜单。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
