# 当课完成鼓励

让家庭看到一次真实完成所对应的努力和课程价值。鼓励是对已发生学习行为的回应，不把一次完课扩展成理解、掌握或习惯已经形成的结论。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)和[高光与反馈规范](../../guides/learning-feedback.md)，并按[服务规则](../../config/service.yaml)核对 `contact` 与相关频控。取得学生与家庭关系、课节身份、完课数据及其更新时间、近期触达和有效事项。

完课记录必须对应当前班期的具体课节。只有完课标记时，输出限制为“已完成/已参与”事实；要称赞某个细节、回答或表达，必须读取相应作品、作答或互动记录，并把原话和解读分开。

## 组织具体鼓励

先核对课程正文，理解当课目标和可提及的真实内容。若有证据，指出一个孩子实际做出的具体行为，再说明它与当课目标的关系；若无证据，使用简洁的参与鼓励，避免编造孩子读出了什么、答得多好或已经理解。

给家长发送私聊文字，附一段可转告孩子的鼓励和转发提示，例如“请替我告诉孩子，今天按计划完成了阅读，值得为这份坚持开心”。有真实作答证据时再改为具体亮点。内容保持正向、具体、短小，不承诺勋章、礼品或其他权益，除非工具和服务配置明确支持。家长同时提出课程问题时，优先回应问题，再依据最新状态决定是否保留鼓励草稿。

## 执行与证据

发送前重新读取完课状态、近期消息和暂停/取消信息，避免在状态变化后发送过时内容。保存实际草稿、课节、使用的证据范围和发送/送达回执；送达不等于家长已读、孩子已听或已经理解。

没有可用作品或作答时，不等待不存在的证据而阻断事实鼓励，也不把“暂无证据”写成能力不足。收到孩子的新表达后，按其实际内容另行记录，可供[阶段学情反馈](../review-learning-progress/SKILL.md)读取，但不会自动生成另一条高光消息。

## 事项完成边界

本次鼓励在允许渠道中实际保存或发送并记录回执后完成。它不关闭补课、方法练习、答疑或反馈等其他事项；如果发送失败或结果未知，保留待处理责任并按原操作号核实。

每节课后最多鼓励一次，按学生、班期、原课节与课程版本识别同一目标；重复同步的完课事件不重新计次。与连续学习鼓励适当合并，仍分别记录目标。全局频控是否适用于本动作及其例外按生效配置判断，不提前将本动作认定为非课堂消息。
