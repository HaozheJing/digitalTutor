# 首日阅读成长纪念

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取班期首日课表和适用首课正文中的内容亮点，核对级别、书目、版本、学生完成数据及同步时间。

## 判断与准备

条件是开课第1天完成首课；报名、建档、首个作品或任意首次互动都不能替代。补记数据需分别核实完成发生日期和本次核验日期，不能以入库日期冒充首日。按学生与本次班期开课首日去重，达成时评估1次，同一成就重复上报继续原事项。

用“第一天就完课”的情感钩子、首课完成事实、真实具体表现与“好的开始”解读组织图文卡。读取实际作答或表达后才写“发现了什么细节”；只有完课记录时鼓励顺利开启阅读，不编造兴趣、理解突破或“过去不会”。有比较基线才使用对比锚点。

## 交付与后续

通过家长私信交付首日完课图文卡，不因制作纪念自动形成新的学习约定。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
