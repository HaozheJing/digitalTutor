# 学习效果沟通

回应家长对效果与继续学习的真实疑虑，帮助家庭理解现状、选择可执行的调整，不以说服续费替代解决问题。

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[沟通原则](../../guides/communication.md)、[答疑规范](../../guides/qa.md)、[学情反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)。

保留家长原话、关注点与当前诉求，区分情绪、事实、期待。查看有效暂停、既有约定、近期沟通与相关服务事项；明确要求暂停时按实际范围处理，不把接受调整方案当作暂停生效的条件。

## 回应疑虑并给出选择

先共情，再围绕家长已说明的关注点读取真实完课数据、高光卡、作品与回答。需要理解教学目标时，按适用级别、书目、版本和课节读取[L2课程资料](../../../knowledge/lesson/【数字员工】L2-课程大纲.md)；涉及课程定位或权益时读取[阅读营产品资料](../../../knowledge/product/阅读营产品知识库.md)。

用具体证据呈现现状，区分参与和能力。只有完课记录时说明参与事实；没有可比作品时不声称能力提升，也不凭一次表现诊断无效果。需要整理证据时调用[阶段学情反馈](../review-learning-progress/SKILL.md)，仍接续原疑虑事项。

提供 A/B 两套与家庭困难相符、实际可行的选择，解释各自投入和观察点，例如调整学习节奏或减少一次练习的负担。方案是选项，允许家庭拒绝或提出自己的安排；需要授权的权益变更先核实，不能保证学习效果或续费回报。补课协商可衔接[补课规划](../plan-makeup-learning/SKILL.md)，明确退费或投诉则交[投诉受理与人工衔接](../handle-complaint-escalation/SKILL.md)，不拖延人工受理以继续劝说。

## 二次跟进与真人协作

按服务规则的 `learning_concern` 及时回应，并保留四十八小时内二次跟进目标。根据生效时限和明确约定保存复核节点；起算或联系人未确定时保留待确认责任，不编造对外承诺。到期先核对新消息和状态，家长要求暂停联系时按范围等待或内部复核，不用跟进目标覆盖暂停。

按实际配置由数字老师协助常规沟通，复杂、持续未解或需升级的情况走 L2→L3 真人路径，以私信接住并准备电话沟通材料；电话由真人执行。记录实际提交、接收人和可兑现时间，未接单时保留责任，不写成已经安排电话。

## 保存与完成

保存证据范围、家长选择或未选择、A/B 方案、暂停/约定变化、实际交付和后续节点。首次回应或发出方案不代表效果疑虑已解决；二次跟进核实执行与家长反馈后再判断调整、继续跟进或结束。没有满意反馈保持未知，使用[共用收尾处理](../close-service-case/SKILL.md)归档实际进展。
