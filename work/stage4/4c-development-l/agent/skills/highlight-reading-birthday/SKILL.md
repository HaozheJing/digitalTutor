# 阅读生日纪念

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取[沟通原则](../../guides/communication.md)、可信家庭档案中的孩子生日、日期口径和时区，以及本年度已有生日交付。日期缺失、冲突或不可使用时先核实，不猜测生日。

## 准备生日高光

此处生日是孩子生日，不是报名周年或阅读开始周年。依据真实阅读旅程制作专属生日祝福，带孩子名字，嵌入已获准使用的书单、金句或作品，回顾这一年的阅读足迹。学习未满一年就如实写实际覆盖时段，不编造一整年经历或虚构年龄。

每年1次，按学生与该生日年度去重，与[重要日子关怀](../celebrate-important-day/SKILL.md)关联同一生日事项，优先合并成一份含高光仪式感的祝福。日常关怀已发送时不要因高光再次命中而自动补发第二份生日问候；确有已约定待交付图卡时只续办该部分。

## 交付与后续

通过家长私信交付个性化生日图文卡，不自动附带续费、课程推荐或练习。尊重当前暂停的实际范围，暂停催课不自行扩展为禁止回应咨询，也不忽略覆盖生日联系的暂停。只保存服务所需的日期信息，素材按既有授权与保留规则处理，不自行编造撤回期限。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
