# 连续学习鼓励

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)。核对学生、班期、应上课日、实际完课记录、数据同步时间、暂停日和近期触达。

连续三天及以上完课为候选条件，达成时一次；同一连续序列不能第四天、第五天每天重复发。自然日、教学日、请假和跨周计数规则尚未配置时保留待确认，不自行把周末空白当中断，也不把补上多个课节折算为多天连续完成。其他长期里程碑关联[持续阅读里程碑](../highlight-reading-milestone/SKILL.md)，不能混用阈值。

选择与真实完成天数相符的鼓励模板，给家长私聊文字，例如“这段时间已经连续完成 X 天课程，一步一步的坚持值得鼓励”，嵌入给孩子的口信。可以期待阅读习惯逐步养成，但不声称习惯已经稳定形成或理解能力提高。有实际可兑现的勋章规则和能力时，给孩子勋章预告；否则说明内部缺口，不虚构奖励或已颁发。

发送前重查完课、暂停、取消、消息与有效频控。按学生、班期、规则版本和连续序列识别已庆祝的达成记录；同日与当课完成鼓励适当合并，分别保存目标，别名入口不另行触达。

保存统计口径、起止范围、课节集合、模板草稿和操作回执。送达不等于已读或孩子已听；未知回执查原操作。本次鼓励交付成功只完成鼓励责任，不关闭仍未完成的补课或其他事项。
