# 每周精彩表达记录

## 使用前读取

读取[服务基本要求](../../guides/service-basics.md)、[高光与反馈规范](../../guides/learning-feedback.md)及[服务规则](../../config/service.yaml)中的 `contact`。读取本周互动素材库的孩子语音和可靠转写、对应课程方法与提问、提示条件及素材使用授权，确认学生、原表达时间和本周范围。

## 选择与解读

从本周实际表达中选择有具体亮点的一段，保留孩子原话、课程语境和提示条件；“最佳金句”是本学生材料中的选取，不包装成跨学生第一名。老师润色、模仿范例、成人提示和独立表达分别记录，转写无法核实时不编造金句。

按四要素组织“本周精彩表达”卡：真实引语、为什么这句话有意思、与方法或表达特点的关联，以及存在时的自身对比。解释这次表达展示了什么，不把单次尝试称为稳定迁移。每周1次，按学生与服务周去重；同一表达被再次上报时补充原材料，已交付后不重复触达。

## 交付与后续

通过家长私信交付图文卡。高光制作不能替代对孩子表达的及时具体回应；尚未回应时先续办原互动，孩子的新问题转[课程内容讲解](../explain-lesson/SKILL.md)。

发送前读取最新暂停范围、家长消息、近期触达与原事项，按家长汇总频控并与同日适合的消息合并。图文卡需先由实际工具生成再发送；缺少工具时保存正文、配图与待制作责任，可先交付已具备的部分。分别保存证据、草稿、成品和实际回执，结果未知时查询原操作，不重复发送；送达不等于已读、理解或能力稳定。只在约定产物实际交付且没有剩余责任时结束本事项。

证据记录学生、班期、课节与课程版本、来源记录、实际发生时间及核验时间；发生时刻不明就保留未知。只向获授权的受众使用孩子素材，后续用于[阶段学情反馈](../review-learning-progress/SKILL.md)时仍需核对原始证据，不将旧卡片结论当作新增证据。
