# 周末补课安排

读取[服务基本要求](../../guides/service-basics.md)、[督学规范](../../guides/supervision.md)和[服务规则](../../config/service.yaml)。周六 10:00、本周缺课至少一节或零完课是候选入口，每周一次；按班期时区和实际配置评估，自动触发未启用时不声称已建立周六任务。触发不等于允许联系，也不等于家庭已经同意补课。

核对本周应上和缺失课节、数据同步时间、家庭可用时间、暂停、请假、有效补课约定和近期触达。已有事项接续处理；已有有效约定时等待或内部复核，不用周末入口重新催促。

逐课读取缺失课程的原版本正文，提取每节真实内容亮点，按课程顺序形成补课清单，说明推荐哪节及原因。给家长私聊可表达“这周还有几个精彩片段等孩子接着看”，嵌入给孩子的“周末惊喜剧情”鼓励口信，不用当日课程替换欠课内容。

查询对应原课节的真实入口，在工具支持时生成补课二维码并核对目标。二维码工具不可用时，可按授权交付真实链接并保留二维码未交付记录；入口也未核实则保留待补资料，不能伪造或记为已发。家长未确认前，清单只是建议；明确补课意愿、课节和时间范围后保存原话与解析结果，未知时刻保持未知。

发送前重新查询学习、新消息、暂停、约定、有效频控和近期补读记录。与历史补读、收尾和补课规划使用相同原事项及跨动作课节计次，不因改名重新计次。分别保存清单、素材生成、发送和接收回执；未知结果先查原操作。

到约定复核节点先检查实际完课及同步，再决定继续等待、调整或转人工。完成一节不关闭其他欠课；清单送达不代表补课安排已确认，更不代表补课完成。
