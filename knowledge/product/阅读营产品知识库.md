# 阅读营产品知识库

## 1. 阅读营产品概况

### 1.1 产品名称与所属平台

- 产品名称：阅读营。
- 产品别称：名著领读计划。
- 所属平台：少年得到。
- 学习平台：少年得到 APP。
- 产品类型：中文分级阅读课程。
- 分级范围：L0—L6，共七个级别，覆盖幼儿园大班至小学六年级。
- 核心学习内容：阅读习惯、阅读理解、阅读方法、表达与写作、作品思想与知识拓展。

### 1.2 使命、愿景与建设目标

- 使命：让更多孩子爱读会读，养成阅读习惯，获得心灵滋养。
- 愿景：成为行业内一流的阅读教育团队。
- 建设目标：打造科学专业的中文分级阅读体系和产品。

### 1.3 本文知识适用范围

本文用于理解阅读营总体产品、分级体系、选书原则、教学方式、功能设计和配套服务。代表书目用于说明选书与教学特点，不等同于完整交付书单。

具体课程的书目版本、学习进度、单节时长、功能开放范围、购买权益和实时学情，应结合对应级别课程配置与用户实际信息确认。计划功能单独列示，其上线状态和适用范围尚未确认。

## 2. 阅读营核心产品定位

### 2.1 建立阅读习惯

**主要学习问题：**不愿读书、只读少数喜欢的类型、读几页就放弃、依赖家长催促、只看课程而不读纸质书。

**课程提供的支持：**

- 用动画场景、名师讲解和互动练习激发阅读兴趣。
- 通过多主题、多体裁的书目拓宽阅读范围。
- 采用每周五天的持续学习安排，帮助孩子形成稳定阅读节奏。
- 通过阅读任务、进度展示和学习激励支持持续学习。
- 将课上原文阅读与课后纸质书阅读衔接起来，推进整本书阅读。

**培养方向：**愿意读、主动读、持续读，逐步读得更广、更深。

### 2.2 学习阅读方法并迁移到表达与写作

**主要学习问题：**逐字读却找不到重点、读完记不住、不会概括复述、学过方法但不会运用、积累词句后不会用于表达。

**课程提供的支持：**

- 教阅读习惯方法，如带着问题阅读、使用符号标记。
- 教理解与整理方法，如人物信息卡、成长阶梯、情绪记录表、性格分析机。
- 教表达与写作方法，如故事手套、故事山、动词连击法、“四个一”素材创新法。
- 用随堂练习、表达任务和阶段测评检验方法运用。

**培养方向：**从读懂一本书，发展到能够运用方法阅读同类作品，并将阅读积累用于讲述、表达与写作。

### 2.3 理解作品思想并获得成长启发

**主要学习问题：**只关注热闹情节、不理解背景、不知道作品想表达什么、不会将故事中的思想与生活联系起来。

课程围绕三个方面展开引导：

| 解读方面 | 引导内容 |
| --- | --- |
| 创作背景与意图 | 了解作品的时代背景、作者经历与创作意图，帮助理解人物和情节。 |
| 思想与观点 | 理解故事中的道理、情感与主题；随着级别提高，练习多角度分析和有依据的评价。 |
| 生活联系 | 将人物经历、成长变化和故事中的智慧与自己的生活联系起来。 |

**培养方向：**理解作品内涵，获得心灵滋养、精神启发与独立思考的机会。

## 3. 阅读营课程形态与学习安排

### 3.1 总体课程安排

| 项目 | 产品知识 |
| --- | --- |
| 上课模式 | 视频 AI 课，结合名师领读与互动答题。 |
| 年课讲次 | 全年 240 节。 |
| 每周学习频次 | 每周五天。 |
| 课程解锁 | 每日零点解锁相应课程，用户自主安排学习时间。 |
| 课程回放 | 年课支持永久回放。具体订单权益需结合购买信息确认。 |
| 主题组织 | L1—L4 采用四周为一个主题月的行课逻辑。 |
| 单节课程时长 | 尚未形成统一口径，存在约 15 分钟、15—20 分钟、20—25 分钟的不同描述；应按具体级别及课程配置确认。 |
| 其他课程形态 | 阅读学院为月课产品；其课时、书目和交付权益不直接套用年课配置。 |

### 3.2 课上学习方式

课上结合名师解读、动画或插画视频、原文电子书与互动练习。孩子在理解故事场景、人物形象和时代背景的同时，阅读原文片段，学习阅读与表达方法。

电子书提供跟读变色功能，复杂或难理解的内容可通过解析弹窗获得阅读辅助。

### 3.3 课后阅读方式

课后根据课程安排阅读纸质书，继续完成整本书阅读。课上重点片段的讲解与课后阅读相互衔接，使孩子逐步理解完整情节、人物关系、语言风格和作品主题。

### 3.4 随堂表达方式

随堂表达包含句式仿写、看图说话、按给定结构复述概括，以及结合生活进行迁移表达。不同级别的表达与写作要求逐步加深。

## 4. 阅读营整体选书原则

### 4.1 四类选书标准

| 标准 | 选书依据 | 代表书目 |
| --- | --- | --- |
| 阅读指导与语文学习要求 | 结合中小学生阅读指导目录、语文课程标准中的阅读主题、体裁和能力方向进行选书。 | 《了不起的狐狸爸爸》《兔子坡》《森林报》《昆虫记》 |
| 校内配套阅读 | 选择“快乐读书吧”推荐作品，以及片段入选语文教材的相关作品。 | 《七色花》《愿望的实现》《格林童话》《稻草人》 |
| 古今中外经典 | 选择经过时间检验的文学作品、作家代表作，以及介绍文化经典和历史人物的作品。 | 《假话国历险记》《西游记》《人间草木》《孔子的故事》 |
| 大奖作品与儿童喜爱的作品 | 选择作品或作者获得权威奖项的读物，以及符合儿童兴趣、具有阅读吸引力的作品。 | 《二年级的比利》《傻狗温迪克》《小巫婆求仙记》《长袜子皮皮》 |

四类标准可以重叠。课程级别与阅读指导目录或教材推荐的年级不必完全一致；入选书目也不意味着所有书都是校内指定必读书。获奖依据可能是作品获奖或作者获奖，不能仅凭书目所属类别认定该书获得某一具体奖项。

书目分类时，同一本书如果符合多个标准，优先归入阅读指导与语文学习要求类别；分类不表示该书仅具有一种入选价值。

### 4.2 书单结构特点

#### 4.2.1 兼顾虚构与非虚构

- 虚构作品包括童话、寓言、小说、神话和科幻故事等，支持人物理解、情感体验、故事结构学习与想象创作。
- 非虚构作品包括科普、历史、人物传记、纪实及相关散文作品等，支持知识拓展、信息提取、整理分析与陌生话题理解。
- 低级别以适合儿童理解的图画故事、童话和儿童文学为主；高级别增加跨学科知识、复杂文本和多种文体。

#### 4.2.2 主题丰富

书目主题涵盖家庭亲情、同伴交往、自我成长、传统文化、人文历史、自然科学、童话神话、冒险与科幻等，兼顾知识学习、情感发展与想象力培养。

### 4.3 分级选书原则

按儿童的阅读能力、心智发展、生活经验及读写学习重点选择适合的作品。阅读载体从图多字少的绘本，逐步发展到注音桥梁书、纯文字章节书、长篇作品和复杂文本。

选书既考虑文字难度与篇幅，也考虑故事结构、背景知识、人物情感和思想内涵的理解难度。

### 4.4 整本阅读与选篇精读的区别

- 多数儿童文学作品通过课上重点片段与课后纸质阅读衔接，推进整本阅读。
- 部分篇幅较长或理解难度较高的经典采用选篇精读，如《西游记》《封神演义》《水浒传》《聊斋志异》《三国演义》《红楼梦》等。
- 介绍书目时应保留“选篇精读”等交付范围，不能将所有课程都表述为完整讲解整部原著。

## 5. 阅读营 L0—L6 分级体系

### 5.1 级别、年级与年龄对应关系

| 级别 | 课程名称 | 对应学习阶段 | 参考年龄 |
| --- | --- | --- | --- |
| L0 | 启蒙阅读 | 幼儿园大班 | 5—6 岁 |
| L1 | 桥梁阅读 | 小学一年级 | 6—7 岁 |
| L2 | 自主阅读 | 小学二年级 | 7—8 岁 |
| L3 | 独立阅读 | 小学三年级 | 8—9 岁 |
| L4 | 深度阅读 | 小学四年级 | 9—10 岁 |
| L5 | 思辨阅读 | 小学五年级 | 10—11 岁 |
| L6 | 主题阅读 | 小学六年级 | 11—12 岁 |

年龄与年级用于理解课程定位，不能单独作为能力达标、报名或跳级的判定标准。

### 5.2 L0 启蒙阅读

**对应阶段：**幼儿园大班，参考年龄 5—6 岁。

**核心学习重点：**不识字也能借助图画进行阅读，细致观察场景、色彩、动作、表情和故事细节，并在图画情境中接触基础汉字。

**阅读理解能力：**读图识字、观察细节。

**表达创作能力：**讲故事、诵读古诗。

**选书方向：**

- 图多字少、便于自主读图的绘本。
- 高品质大奖绘本。
- 将诗词转化为直观图画情境的诗词绘本。
- 品质养成、社交表达、艺术想象、科学通识和名著启蒙等主题绘本。

**代表内容：**《神奇雨伞店》《一颗种子掉下来》《爱是什么》《神秘邻居》《看呀，那水变了样》及《池上》等诗词绘本。

**绘本配置：**12 个大奖绘本、12 个诗词绘本、24 个主题绘本。

**主要用户需求：**减少对家长讲读的依赖，拓宽绘本类型，提高观察与理解能力，练习连贯讲述，建立阅读兴趣与持续参与的习惯。

### 5.3 L1 桥梁阅读

**对应阶段：**小学一年级，参考年龄 6—7 岁。

**核心学习重点：**从看图过渡到读字，并用完整词句说清楚画面与故事内容。

**阅读理解能力：**图文结合、代入人物。

**表达创作能力：**组词造句、看图说话。

**选书方向：**

- 字多图少、提供拼音辅助的桥梁书。
- 贴近校园、交友和自我成长的故事。
- 充满想象的动物童话与短篇奇幻故事。

**代表书目：**《青蛙和蟾蜍》系列、《草莓山谷的小妖怪》《大嘴巴河马》《小巴掌童话》《小猪唏哩呼噜》《金波童话集》。

**方法与练习示例：**观察谁、在哪里、做什么、发生了什么；使用“首先、然后、最后”等过渡词；比较角色特点，代入角色猜测行为和故事走向。

**主要用户需求：**从听故事发展到主动看文字，适应拼音辅助阅读，理解句段含义，练习复述与看图表达，并将课堂方法用于生活与写话准备。

### 5.4 L2 自主阅读

**对应阶段：**小学二年级，参考年龄 7—8 岁。

**核心学习重点：**理解词句与人物情感，学习修辞仿写和看图写话，把故事内容表达成较完整的段落。

**阅读理解能力：**理解词句、体会情感。

**表达创作能力：**修辞仿写、看图写话。

**选书方向：**

- 逐步适应纯文字阅读与更长的故事。
- 探讨友情、亲情、自我成长与换位思考的作品。
- 科学启蒙、传统文化和名人故事等知识拓展读物。

**代表书目：**《了不起的狐狸爸爸》《假话国历险记》《二年级的比利》《七色花》《愿望的实现》《兔子坡》《科学家的故事》《〈庄子〉里的大自在》。

**方法与练习示例：**理解诗意、收集好词；用五感小人表达诗句意思；理清人物关系与内心情感；学习比喻并仿写句子；用情节路线图介绍故事。

**主要用户需求：**巩固纸质书阅读兴趣，减少拼音依赖与长文本畏难，理解故事中的道理，提升复述条理，并将词句与方法积累迁移到写话。

### 5.5 L3 独立阅读

**对应阶段：**小学三年级，参考年龄 8—9 岁。

**核心学习重点：**完整概括故事、总结道理、积累素材，并展开想象进行续编和写人记事。

**阅读理解能力：**概括复述、总结道理。

**表达创作能力：**写人记事、素材积累。

**选书方向：**

- 篇幅增加、情节与线索更丰富的纯文字作品。
- 语言优美、富有想象力的童话。
- 支持自我认识与成长的儿童小说。
- 帮助理解行为后果和道理的经典寓言。

**代表书目：**《绿野仙踪》《格林童话》《安徒生童话》《柳林风声》《长袜子皮皮》《伊索寓言》《克雷洛夫寓言》。

**方法与练习示例：**用五指法复述故事；引用童话说明道理；从不同角度描写人物；用故事山列提纲；用文采调色盘丰富细节；通过符号批注积累素材。

**主要用户需求：**坚持课后阅读，平衡课业与阅读时间，提高长文本阅读流畅度，发展概括与提炼能力，将方法迁移到阅读理解和写作任务。

### 5.6 L4 深度阅读

**对应阶段：**小学四年级，参考年龄 9—10 岁。

**核心学习重点：**从人物语言与行为分析特质，依据线索猜测推想，学习结构与手法，生动地写人记事。

**阅读理解能力：**分析人物、猜测推想。

**表达创作能力：**结构提纲、创作手法。

**选书方向：**

- 中外神话，学习理解和塑造鲜明人物。
- 冒险故事，理解目标、挑战、解决的情节结构。
- 自然科普，探索现象背后的原理。

**代表书目：**《中国古代神话》《希腊神话与英雄传说》《纳尼亚传奇》《八十天环游地球》《森林报》《细菌世界历险记》《西游记》（选篇精读）、《封神演义》（选篇精读）。

**方法与练习示例：**用人物卡片分析角色；依据反应推测情节；学习游历型故事结构；用故事六要素搭建提纲；通过人物对话和连续动词表现人物特点。

**主要用户需求：**维持课后阅读动力，理解文学性较强的语言和作品思想，补充历史与科普背景知识，将阅读积累用于结构安排、细节描写和素材运用。

### 5.7 L5 思辨阅读

**对应阶段：**小学五年级，参考年龄 10—11 岁。

**核心学习重点：**理解思想主旨，多角度分析问题和评价人物，关注人物性格变化，形成有依据的观点。

**阅读理解能力：**思想主旨、多角度评价。

**表达创作能力：**借景抒情、观点立意。

**选书方向：**

- 长篇作品与情节、人物关系更复杂的文本。
- 可以引发多角度分析和独立判断的作品。
- 散文及自然科学、经济、宇宙、人文历史等跨学科读物。

**代表书目：**《尼尔斯骑鹅旅行记》《少年读史记》《人间草木》《昆虫记》《给孩子的小岛经济学》《跟着霍金看宇宙》《水浒传》（选篇精读）。

**方法与练习示例：**提取关键信息，总结中心思想；用双面镜法评价人物；分析以物寄情等表达手法；学习读后感的观点与立意。

**主要用户需求：**在课业压力下保持有质量的阅读，提高信息提取与情感理解能力，避免只浏览情节，将阅读转化为思辨、表达和写作能力。

### 5.8 L6 主题阅读

**对应阶段：**小学六年级，参考年龄 11—12 岁。

**核心学习重点：**综合运用小学阶段阅读方法，开展真题演练，学习多文体写作，并拓展对复杂作品和跨学科主题的理解。

**阅读理解能力：**真题演练、综合运用。

**表达创作能力：**多文体写作、高频主题。

**选书方向：**

- 支持小学到初中阅读衔接的文学作品。
- 科幻作品，理解科学背景与故事世界观，学习想象创作。
- 古文、人文历史、生物等领域的读物。
- 人物故事，帮助理解榜样、成长与人生志向。

**代表书目：**《鲁迅小说选读》《红岩》《镜花缘》《2001 太空漫游》《刘慈欣作品精选》《10 岁开始学古文》《孔子的故事》《所罗门王的指环》《用显微镜看大象》《向上生长》，以及《三国演义》《红楼梦》等选篇精读内容。

**方法与练习示例：**综合使用阅读策略；提取科幻作品关键信息，制作世界观记录表；学习记实、想象与应用等不同文体的表达。

**主要用户需求：**在小升初与课业压力下安排阅读，理解文学作品的思想情感和时代背景，积累古文与复杂文本阅读经验，提高方法综合运用能力。

## 6. 阅读营阅读能力与方法体系

### 6.1 五个阅读能力维度

| 能力维度 | 能力关注点 |
| --- | --- |
| 提取信息 | 找到文本中的关键信息，识别与任务有关的人物、事件和知识。 |
| 分析理解 | 理解词句、人物关系、行为原因、情感与情节之间的联系。 |
| 概括总结 | 梳理主要内容，概括事件、情节、主题或知识要点。 |
| 猜测推想 | 根据文本线索，对人物行为、故事走向或隐含信息进行推想。 |
| 评价鉴赏 | 评价人物与观点，理解作品的语言、情感和思想价值。 |

### 6.2 阅读与表达方法分类

| 方法类别 | 方法或工具示例 | 运用方向 |
| --- | --- | --- |
| 阅读习惯 | 带着问题阅读、符号标记与批注 | 明确阅读目标，记录重点和疑问。 |
| 人物理解 | 人物信息卡、人物卡片、成长阶梯、情绪记录表、性格分析机 | 整理人物信息，理解情绪、性格和成长变化。 |
| 故事概括 | 故事手套、五指法、情节路线图 | 梳理故事要素和情节，支持复述与概括。 |
| 内容结构 | 故事山、故事六要素 | 组织故事结构，辅助表达提纲与写作。 |
| 语言与细节 | 五感小人、文采调色盘、动词连击法、修辞仿写 | 感受和运用词句，增加描写的具体性与生动性。 |
| 观点与素材 | 双面镜法、“四个一”素材创新法 | 支持多角度评价和素材运用。 |

上述名称为课程中的方法或工具名称。具体操作步骤、适用题型和练习要求需结合对应课程知识确定。

### 6.3 各级别阅读策略的发展方向

| 级别 | 阅读策略重点 |
| --- | --- |
| L0 | 观察图画细节，提取画面信息，复述主要内容，并根据画面线索展开想象。 |
| L1 | 借助图画预测内容，结合图与文理解故事，学习指读。 |
| L2 | 联系上下文和生活理解词句，提出感兴趣的问题，学习不出声、不指读的默读。 |
| L3 | 对不理解的内容提问，初步概括主要内容，边读边想象画面，巩固默读。 |
| L4 | 复述作品大意，批注重点与疑问，学习略读，把握文章内容。 |
| L5 | 浏览与筛选信息，抓住说明性文本要点，分析表达顺序与思想情感。 |
| L6 | 根据阅读目的综合运用略读、浏览等方法，开展有依据的讨论和探究性阅读。 |

## 7. 阅读营学习激励与互动功能

### 7.1 守护小火苗

**功能内容：**以小火苗展示连续学习天数，通过成长动画提供学习进度反馈。

**连续学习规则：**按时完成当日课程的“正读”可以累积火苗；“补读”会中断连续记录。具体判定时点、恢复机制和用户当前记录需结合功能配置及实际数据确认。

**学习作用：**让坚持学习可视化，支持按时完成课程和形成连续阅读习惯。

### 7.2 主题月连续阅读挑战

**功能内容：**通过连续打卡解锁里程碑奖励。

**学习作用：**把长期阅读目标拆成短期任务，持续提供完成任务的反馈与成就感。

### 7.3 完课提醒小组件

**功能内容：**在手机桌面展示学习进度，提供进入学习页面的快捷入口。

**学习作用：**缩短学习操作路径，提醒孩子按时学习，减少遗忘。

### 7.4 排位赛 PK

**功能内容：**基于学习获得的经验值进行周排名与段位升降。

**主要机制：**

- 系统每周匹配 30 名经验值相近的用户进行 PK。
- 根据当周经验值总额实时排名。
- 根据排名结果进行段位升降。
- 达到相应段位可获得奖励。
- 阅读营、素养课、知识出版等课程内容可参与经验值体系。

**学习作用：**通过周目标、竞争与阶梯奖励支持持续学习。具体经验值计算、奖励内容和升降级阈值尚未明确。

## 11. 阅读营常见产品问题

### 11.1 孩子已经能自己读书，阅读课还能提供什么？

阅读课提供作品背景与思想解读、阅读方法、信息整理、人物分析、概括复述和表达练习。孩子能独立认读文字后，仍可继续发展文本理解、深度思考和方法迁移能力。

### 11.2 阅读营怎样帮助孩子形成阅读习惯？

通过每周五天的学习节奏、课上讲解与课后阅读任务，以及进度展示、连续学习挑战和伴学提醒支持持续阅读。习惯发展与孩子原有基础、参与情况及实际阅读练习有关，不能仅凭课程时长推定已经形成习惯。

### 11.3 阅读营是否只让孩子看动画？

课程结合动画或插画视频、名师讲解、原文电子书阅读、互动练习和表达任务。纸质书阅读也是课程学习的组成部分。

### 11.4 阅读营如何衔接表达与写作？

从图画讲述、组词造句、看图写话，逐步发展到故事概括、写人记事、结构安排、描写手法、观点立意和多文体写作。孩子通过仿写、复述、创编及生活联系等任务，将阅读内容转化为表达练习。

### 11.5 阅读营所有书都是校内必读书吗？

书目结合阅读指导、校内配套阅读、文学经典、获奖作品与儿童兴趣等标准选择，包含校内推荐作品，也包含其他适合分级阅读的作品。

### 11.6 阅读营所有作品都讲完整原著吗？

多数儿童文学课程推进整本书阅读；部分经典采用选篇精读。具体范围需按书目和课程配置确认。

### 11.7 如何了解孩子的学习表现？

通过阶段学情报告查看阅读量、阅读时长、完课率和能力表现；L1—L6 还可通过季度测评了解阅读方法的实际运用情况，并结合教辅沟通确定巩固方向。

### 11.8 年课和阅读学院月课是否使用同一套交付配置？

年课与月课是不同课程形态。全年 240 节、季度测评和全年伴学等配置属于年课知识，不能直接推定月课也具有相同课时与权益。
