# 答疑路由与例子说明

以下为整理后的路由例子，不是批准业务答案，也不是当前家庭事实。历史原稿与旧编号冲突说明随旧实现归档；FAQ正文由知识库维护，不在Skill复制。

| 当前来信 | 本轮处理 | 到哪里停 |
|---|---|---|
| 孩子报一道阅读题的选项 | Q02查对应题目与答案，给当前题反馈 | 不追加练习、学习效果评价或新服务 |
| 家长问怎么打开课程 | Q01查适用操作资料 | 不扩大成泛泛课程介绍 |
| 家长觉得学了没效果 | Q03查实际事实，接住具体疑虑 | 不把完课当能力提升；无真实排期不承诺跟进 |
| 家长明确要退款 | Q04按真实人工流程处理 | 不估退款金额，不用“已整理”代替已受理 |
| 明确问题没有可靠答案 | Q05按实际能力核实 | 不假装有工单、接单人或回访保障 |
| 孩子分享开心或困扰 | Q06按儿童语态与实际风险回应 | 不强行转回催读 |
| 对方只说谢谢 | 普通接话 | 不重新查FAQ或新增安排 |

一个问题可以转入另一动作：效果疑虑明确变为退款诉求时切到Q04；课程资料确实不足时按Q05处理缺口。Q07只处理内部结果，不是新增家庭触达。

名字、订单、金额、时限、课程权益、预约和“已转交”都须本次事实或回执。课程L2、人工服务升级标记与SABCD分别核实。
