# 节日互动

## 动作目的

在节日里给孩子送上一份专属于自己的小礼物。让孩子从画面和祝福中感受到，老师记得自己的名字，也记得自己喜欢什么、最近读到了什么，愿意把故事里的趣味和温暖带进自己的生活。

用有想象力的画面和真诚亲近的话增进老师与孩子的熟悉感，让阅读成为彼此交流的共同话题。孩子可以开心地收下，也可以顺着画面分享自己的发现、愿望或节日生活；收到祝福本身就足够，不要求回答问题或完成任务。

## 本次事项

在元旦、除夕、中秋节、端午节当天，为孩子生成一张个性化祝福图片，配一段节日祝福文字，通过微信图文送达。四个节日共用本 Skill，由智能体结合节日氛围和孩子的实际情况构思。

使用事项提供的业务日期及经过核验的节日日历。元旦按公历，除夕、中秋节、端午节核对当年的农历对应日期，不能按往年公历日期推算，也不能把除夕写成大年初一。同一孩子、同一年度、同一节日只主动祝福一次，与已有节日关怀共用去重事实，避免重复发送。

## 执行方法

**先找到属于这个孩子的细节。** 从宿主绑定档案确认昵称，结合 `learning_query(day)` 和本轮上下文了解已学内容、近期交流和孩子明确表达过的兴趣。需要原话时用 `conversation_read(source_id)` 核实；使用具体故事情节、角色或知识点时，通过课程读取工具核实对应内容。

从中选一个最适合节日的细节作为创意起点。孩子喜欢的角色、反复提过的兴趣、读过的有趣场景，或曾经表达过的一个想法，都可以使用。不把“学过”写成“最喜欢”，不把读到结尾写成全书读完，不为了个性化编造孩子的经历或能力。信息较少时，可以用已确认的昵称和当前阅读内容构思，不必追问家庭来凑素材。

**把节日与阅读细节连成一个画面。** 先确定这次想送给孩子的祝福，再围绕它设计画面，让节日元素和孩子熟悉的阅读元素产生自然联系。画面要让孩子觉得有趣、愿意多看一会儿，不能只在通用节日海报上换个名字。

- 元旦可以围绕新一年的好奇、发现和小小愿望展开，带来明亮、轻快的开始。
- 除夕可以围绕温暖、团聚和迎接新年展开，不假定孩子一定与哪些家人一起过节。
- 中秋节可以围绕月亮、思念、分享和团圆展开，把故事中的想象带进月夜。
- 端午节可以围绕龙舟、粽子、夏日和安康展开，让祝福有活力，也有生活气息。

这些是构思方向，不是固定模板。选择与本次主题有关的元素即可，不堆满节日符号，也不把四个节日画成同一张图。可以让故事角色进入想象中的节日场景，但不把创作情节说成原著内容或孩子真实发生过的经历。

**生成一张真正可送给孩子的图片。** 将节日、孩子昵称、选定的阅读元素、画面主体、人物活动、氛围和需要出现的短文字整理成清楚的生图要求，再调用宿主实际提供的生图能力。采用适合孩子观看、在手机上也清楚的构图和视觉风格，主体突出，画面温暖、有趣。图片可包含孩子昵称和简短祝福，不把整段微信文字塞进图里。

使用 `generate_image(content, request_id)` 生成图片，读取生成返回中的真实成图与宿主检查结果（由宿主执行检查），核对返回的 `asset_id`，核对节日、昵称、文字可读性及画面是否符合构思。若出现错字、错名字、明显画面错误或与课程素材不符的内容，修正后再发送。只有生成回执和可查看的图片，才算图片已制作完成；提示词、文件名或链接本身不算成品。

**配上直接对孩子说的祝福。** 读取 `reply-style`，使用“孩子昵称”或“孩子昵称＋宝贝”开头，亲近地送出祝福。可以从画面中的一个小细节说起，让孩子明白老师为什么送这幅图，再自然说出对孩子的祝愿。图与文字表达同一份心意，文字不必逐项描述画面。

祝愿可以是快乐、安康、好奇、勇气、发现和分享，结合当前孩子与节日自然表达。不要把祝福写成学习总结，不借节日催课、要求补读或布置练习，也不许诺成绩与能力结果。不固定在末尾加问题，孩子愿意回应时再顺着真实表达交流。

**核验后完成图文交付。** 使用宿主提供的本次节日候选，发送前核验日期、联系条件、暂停要求和历史送达。图片作为微信图片消息发送，祝福作为文字消息发送，不用图片链接代替图片。文字按 `reply-style` 的称呼、字数与表达要求处理。

沿用宿主已装载的本次节日候选与执行令牌，发送前条件由宿主复核。检查通过后调用 `send_message(candidate_ids=[本任务候选],body=祝福文字,asset_id=已核验图片,execution_token=本任务令牌,generation_token=本次生成令牌)`，一次提交图片与文字，分别核对回执。不得降级成只发文字，不自行填写图片地址；需要重做时重新生成并取得实际检查结果。

若生图或新图片发送失败，记录具体缺口，本次图文祝福保持受阻，不把纯文字降级当作完整完成。部分内容已送达时保留各自回执，避免把整组重发；结果不明时先查明，不盲目重试。

## 执行后如何判断完成

针对当前孩子和当前节日生成的图片、配套祝福文字均实际送达，才算本次节日祝福完成。记录所用个性化依据、成品与交付结果，生成成功、接口受理和最终送达分别判断。

孩子有真实分享、提问或积极回应时，再记录实际互动。没有回复不代表祝福无效，也不据此追问或催促。
