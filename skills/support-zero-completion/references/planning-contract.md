# S05 初次关怀后台契约

本契约供每日规划和工程核验读取，普通表达任务不预装。

```json
{"skill":"support-zero-completion","enabled":true,"fixed_time":"19:00","scope":"initial_contact_only"}
```

沿用每日规划入口，只安排当周最近连续两个应学日期均尚未完课的初次关怀；当前日必须是其中最后一个应学日。完整课表与逐课记录必须覆盖当周至当前日；无课和空白不是零完课。两日中出现任何实际完课（包括补读历史课），或其中任一应学课已完成，都不触发。早间规划只代表候选，到19:00发送时重新查询并复核，不声称当天学习时间已结束。

每自然周最多一次；同课跨动作每周最多两次、日联系额度、暂停、静默窗口、任务绑定及执行令牌沿用原交付机制。候选只包含这两个应学日的未完课，以稳定课节ID核验共享频控。事实有变化时使用原任务重新复核；不通过另造任务绕过拒绝。

每日规划→绑定S05任务→执行时实时查询家庭、课表学情、近期交流及建议课正文→模型拟消息→deliver_proactive事务内复核→后台按实际回执登记。accepted保持awaiting_delivery，sent才确认送达；未知或部分失败不重发。未接入生产学习提供器，隔离验证使用合成开发夹具和模拟出口。

本次只接初次关怀。48小时履约核验与真人转交未接，不启动计时，不承诺已排期或已转交；家长未明确承诺不算已约定。
