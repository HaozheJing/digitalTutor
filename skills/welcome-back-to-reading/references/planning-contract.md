# S11 完课入口契约

```json
{"skill":"welcome-back-to-reading","enabled":true,"trigger":"lesson.completed","delay_minutes":30,"minimum_overdue_before_completion":5,"owner":"host_completion","delivery":"deliver_proactive"}
```

以同一报名下已过应学日且当时尚未完成的课为缺课。恢复前至少5节，首个完课事件为欢迎锚点。一次积累缺课的恢复阶段只欢迎一次；其后仍有至少5节欠课时的连续完课不会反复欢迎。降至5节以下后，未来重新积累到至少5节并再次完课，才可形成新事项。数据不全不推断门槛。

从原始完课时间加30分钟；不以收到事件或开始上课时间计时。重复事件、刷新和重启沿用同一任务、事项、版本和回执。午夜跨日按真实延迟后的日期处理，过期不借新日期补发。原有家庭暂停、交谈优先、即时事实复核和交付限制继续适用。

同一恢复事件的S02/S03/S04/S06由S11欢迎覆盖，避免重复表扬和催补；不修改其他事件的独立资格。S11由宿主排期，既有四项模型规划协议保持不变。
