# 持续事项的内部检查

此 Skill 保留用于历史检查记录和兼容；近期不自动创建检查任务，不据此扩展 SOP。

这是内部检查，无需 service-policy，不发送消息，不创建对客任务，不直接恢复联系。读取宿主已装载材料中的账本、目标、最新完课事实、家庭反馈和交付状态。宿主预加载的本 Skill 与资料可直接使用；资料变化时通过 workflow_read(view="refresh") 刷新。

一次性鼓励只有最终 sent 才算完成，accepted 只是受理。补读建议以最终 sent 完成本次交付，关联学情独立记录；家庭“周末补”是意向，不能当作完课。逐课完成事实才可更新目标；部分完成保留其余目标，发送前全部完成可解决事项并取消未执行任务；已完成的交付事项不重新打开。暂停和停止跨完课信号持续有效，不能用旧话恢复。

记录 service_case_review(reason)，仅写有证据的进展或缺口。该操作不联系家庭，不建立每日追问，也不无限重排检查。没有新进展可以保持等待。最后 service_task_finish(outcome="no_contact",reason=实际检查结果)。资料不足使用 blocked，不编造学习或家庭反馈。
